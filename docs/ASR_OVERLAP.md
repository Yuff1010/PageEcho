审计重放每块已保存的模型响应，还原完整重叠上下文，并逐块确认重新计算的归属 units 与实际 checkpoint 完全相同。没有重新识别音频，也未用出版原文作为参考。在共有时间附近，查找同时覆盖双方归属切口、至少四字符且唯一的相同文字，并检查配对时间一致性。

86 处中有 83 处具备这样的明确模型上下文，其中 5 处的共同文字被拼接丢失：

| 切分点 | 丢失文字 | 原因                               |
| ------ | -------- | ---------------------------------- |
| 09:30  | 足       | 两边的独立中点判断均排除该字       |
| 15:00  | 似       | 两边的独立中点判断均排除该字       |

四处归属丢字原先都没有 `BOUNDARY_CONFLICT`，说明只检查范围相交不能覆盖漏字。基线 `cache/asr-evaluation/ctc-diagnostics/overlap-baseline-0.8.3-final.json` 保留双方原文、切口、原时间及丢失文字。

## 实现与缓存

后处理版本升至 3，checkpoint 保存完整 `contextUnits` 与基本归属 `units`。加载缓存时验证原范围、字符时间及从完整上下文重新计算的归属是否一致；缺失、越界或归属不一致的块重新计算。新处理参数进入缓存 key，旧块不按新规则直接复用；既有文稿和纠错仍由预览/采用保护。独立 0.7.0 组件包不变。

拼接使用共有上下文中的字符位置区分“同一字被两边选中”和“相邻两个相同的字”。只在唯一匹配、时间相容、完整原生 unit 可取出的情况下恢复或去重；恢复直接采用右窗口已保存的时间。不能证明、需要拆开不可分词元或时间不一致时，保留选择结果并增加 `BOUNDARY_CONTEXT_UNRESOLVED`，不猜字或均分时间。

保留原时间可能产生小范围交叉；阅读段合并所有受影响的相邻范围并保留文字顺序，不裁剪字符时间或删除冲突标记。修复还覆盖一个原生范围向前跨过多个阅读段的情况。

对同一批旧原始输出应用新拼接规则，`cache/asr-evaluation/ctc-diagnostics/overlap-prospective-0.8.4-final.json` 得到 83/83 处共同文字完整保留，3 处仍缺少明确上下文；四个字恢复，“愤愤”保留，两个真正的重复归属仍去重。生成文稿通过 TypeScript M2 原音频哈希/范围校验。它是固定模型输出的处理链对照，**不是新模型运行、人工听审或有声书 CER**。

新规则没有追求警告变少：同一批旧输出仍有 45 个范围冲突、4 个文字恢复、2 个共同归属去重和 3 个上下文待复核标记。完整报告保留全部证据。
