# 有声书与电子书关联

有声书目录的“关联电子书”、电子书卡片的“关联有声书”，以及原文工具中的“从电子书书架选择原文”，使用同一个关联窗口。选择同作品、同正文版本后，点击“关联并用于伴读”。同名书只作为候选提示，必须确认；已经绑定的原文与电子书使用同一内容哈希和解析版本时，会自然显示关联。

关联复用 `original_documents` 的正文身份及 `book_originals`，不复制整本正文，也不增加数据库 schema。阅读进度、音频进度和人工同步点分别保存。更换关联保留旧原文版本及其校正；解除关联保留电子书、音频、阅读进度和历史映射。移除电子书记录不会删除仍用于伴读的原文。

## 按当前位置切换

- 在听书字幕页点击“从当前进度阅读”：当前声音有有效映射时，定位对应原文；只有片段时间时定位片段起句，采用了逐句声音时间时定位对应句。当前声音没有映射时保留原阅读位置，并显示状态提示。原文尚未进入电子书书架时，这个明确的打开操作会将其加入书架。
- 在关联电子书中点击“从此处听书”：查找所有关联演播版本当前有效映射。唯一位置直接定位并播放；多个位置必须选择具体集数和时间，选择后开始播放；没有同步点时，可以继续阅读或点“准备字幕并匹配”启动工作，保留原收听位置。不会按阅读百分比估算声音位置。
- 已过期的音频、转写、匹配规则，以及标为旧来源或沿用来源的人工同步点，不用于自动位置转换。声音句间空缺保持空缺。点击候选前再次核对当前映射；切集或导航会取消尚未完成的跳转。

打开电子书阅读保留声音的播放／暂停状态；“从此处听书”是明确的播放动作，会定位并开始收听。普通导航不改变播放状态，书签及独立阅读设置不变。原文、字幕和电子书正文只在明确采用编辑结果时改变。

## 自动匹配与空缺

关联后，有正式字幕的集数按有界队列分批匹配，当前操作保持优先。关联书的匹配在下次启动时从轻量元数据恢复，不需要先打开每一集。启动自动恢复最多扫描 10,000 个有正式字幕的关联集，包含已完成集；超限时记录日志，其余仍可按需匹配或重新关联。队列、单次处理和集数都有上限；普通播放与匹配失败相互独立。

规则 5 增加可靠双侧锚点之间的局部恢复，但冻结《青山》及《呐喊》复评覆盖数量未变，不能宣称真实准确率已提高，见 [前后文匹配验证](ORIGINAL_ANCHORS.md)。原文跟随遇到未匹配位置时，可显示当前实际转写字幕，或切换到转写字幕继续看。原文工具的“只看未匹配”筛选方便逐段确认、保留空缺或调整同步点。
