# 界面视觉约定

书架、书源、播放器与设置共用 `src/renderer/src/appearance.css` 的颜色变量。阅读纸色独立于应用主题，但纸色区域内的控件必须使用同一组局部变量，避免深色应用的文字出现在浅色纸面上。

- `--ui-text`：主要文字；`--ui-muted`：说明与次要信息。
- `--ui-bg`、`--ui-panel`、`--ui-field`：页面、卡片和输入区域。
- `--ui-line`：分组边界；`--ui-control-line`：交互控件边界。
- `--ui-accent`、`--ui-on-accent`、`--ui-accent-soft`：强调色、强调色上的文字和选中背景。
- `--ui-danger` / `--ui-danger-bg`：错误；`--ui-warning` / `--ui-warning-bg`：需要注意的信息。

新用户默认跟随系统主题，已保存的深浅主题选择继续生效。电子书透明抽屉的实际底色由 `reader-panel.ts` 计算；调整全局面板色时需要同步其底色并验证对比度。

## 字体与操作

应用基础字号 15px，常规控件至少 14px，辅助信息至少 13px。伴读正文保留用户选择的 16–28px，新用户默认 22px；已保存的字号继续生效。封面上的装饰字与缩略封面、SVG 图标内的数字不属于界面文字下限。

主按钮高度至少 40px，常规图标按钮点击区域至少 36px，主导航高度 48px；播放器高度 96px，为标题、进度与字幕状态保留空间。键盘焦点使用清晰的轮廓，不依赖颜色变化来表达焦点。常用播放与书籍操作无需悬停即可发现。

## 设置层级与滚动

伴读采用完整书页：64px 精简顶栏、居中最大 760px 的宋体正文、页底阅读状态与全局播放器。侧栏及旧页面标题隐藏，正文为唯一阅读滚动区。正常模式连续排版、首行缩进，不显示句子编号或逐句操作；句子仍可点击、用键盘跳转播放。正常模式只给当前句（未定位时为首句）一个 Tab 停靠点，避免整页逐句按钮挤占键盘导航。

阅读设置、字幕生成、导入、诊断和校对工具放在覆盖式抽屉中，打开抽屉不改变正文排版宽度。搜索同样按需打开。校对与标注模式显式开启后恢复逐句编号及操作，关闭后恢复书页。无文稿时才在正文中央显示生成与导入入口。

伴读页顶部直接切换“转写字幕 / 小说原文”，不在工具抽屉里切换文字来源。小说原文沿用同一书页与阅读主题，正文不显示句子编号；目录、全文搜索及原文工具采用覆盖面板。原文工具分为“原文来源”“匹配与校正”“字幕导出”，与转写字幕的文稿工具各自独立。书架侧栏只保留书架和书源，底部播放器“听书字幕”为当前音频的统一伴读入口。

`CompanionTranscriptBody.tsx` 保留高亮、点句播放、自动跟随、自由阅读、搜索定位、分页与校对逻辑。`companion-prose.ts` 只按文本换行、停顿和保守篇幅做视觉分组，不改写存储文字、顺序或时间范围；选中文字不会跳转播放。

缓存与任务采用侧导航与卡片分组，诊断路径按需展开。收听工具把播放、定时放在前面，字幕与缓存、书签各自分组，并提供页内跳转。

`main.tsx` 先导入基础样式，再导入组件。组件样式应限定作用区域，避免旧的全局规则覆盖组件的字号、间距和状态颜色。

## 验证

执行 `npm run build`、`npm run lint` 和相关桌面测试。`scripts/visual-design-review.ts` 在临时用户目录中使用本地样本，通过真实 IPC 生成截图和检查报告：

```powershell
node node_modules/tsx/dist/cli.mjs scripts/visual-design-review.ts
```

截图覆盖深浅主题、1366×900 与 1024×768 窗口、书架、长文伴读、设置及电子书抽屉；检查横向溢出、键盘焦点、共享文字颜色至少 4.5:1 的对比度、正文高度至少占窗口 60%、默认无校对工具及抽屉不改变正文宽度。报告与截图输出在被 Git 忽略的 `cache/visual-design-review/`。`tests/desktop/companion-book.spec.ts` 另验证真实鼠标选文、键盘跳句、自动跟随、搜索、翻页、专注模式及 720×600 最小窗口。
