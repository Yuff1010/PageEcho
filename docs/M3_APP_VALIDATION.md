# M3 应用任务验收

日期：2026-10-20（America/New_York）。版本 0.4.0，SQLite schema v4。本记录验证应用任务与文稿保护；模型准确性和时间精度仍以 [评估记录](M3_EVALUATION.md) 及后续人工参考为准。

## 已实现

- 受限 IPC、原生组件配置选择器、显式引擎/设备选择和逐块生成文稿。
- SQLite 保存排队、运行、取消中、完成、失败和取消状态，串行调度；重启续接并递增 attempt，完成块校验后复用。
- 切换章节取消其他章节任务；正常退出先保存续接状态，确认拥有的 worker/FFmpeg 停止后再关闭数据库。
- 无文稿时逐块自动显示；已有稿件或人工修改时独立预览，明确采用且修订匹配后替换。迟到结果、旧音频及旧 attempt 不覆盖新内容。
- 每句小范围纠错保留 ID 和时间戳；大幅修改和修订冲突拒绝覆盖。拆分合并及重新对齐尚未实现。
- 缺少组件、无效配置、失败或取消均可保留普通播放。
