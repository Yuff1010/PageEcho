# 当前集转写稿全文搜索

日期：2026-10-21（America/New_York），独立预览 `0.10.0-dev.5`。已补齐开发计划中的转写文稿搜索；导入小说原书的搜索继续见[原文搜索与字幕导出](READING_TOOLS.md)。

## 使用与边界

在“伴读阅读”的转写稿视图展开“搜索当前集文稿”，输入 2–100 个字符。检索当前显示的整集已保存文稿或生成稿预览，可跨相邻片段，忽略全半角、大小写、空白与标点。至少需要两个有效文字字符；只含标点的输入会提示错误。相同句范围内的重复出现合为一处，结果按文稿顺序每页 20 处，可直接到末页。

点结果进入自由阅读，显示并标记命中的句范围；折叠标注中的命中会展开。跨页命中在翻页后仍可查看。定位不触发音频跳转，保留原播放位置及播放/暂停状态；点正文句子仍按原有行为跳转声音，“回到当前播放位置”恢复跟随。搜索结果的时间为已有片段原始坐标，不生成新的声音边界。

纠错、重新导入、切集、进入/退出生成稿预览及文稿修订会使原搜索快照失效。结果和命中标记即时清空，重新展开后搜索当前文稿。查询不写入数据库、不改源文件或 ASR 文字；未配置转写组件时也能搜索已有文稿。此次范围为当前集，未增加跨集文稿聚合搜索。

## 实现与保护

首次展开时建立一个原生 Web Worker，按文稿 ID/修订持有不可变副本。索引以规范化字符位置和源片段范围对应，不在播放器交互线程扫描十万句；分页复用当前查询的范围缓存。生成稿预览采用自己的身份/修订，沿用同一生命周期保护。

取消搜索会终止旧 worker 并重建索引；30 秒超时或加载失败可重试。组件卸载或版本变化后终止 worker，并以存活标记和请求序号拒绝迟到事件。worker 为构建中的同源独立资源，没有新增 IPC、数据库表、Node 权限或放宽 CSP。检索与结果定位均在现有受限 renderer 的文稿副本中完成。

文稿阅读区采用可滚动容器，保留至少 180 px；最小窗口中播放器和定位后的命中句可见。六位句号使用固定数字宽度并禁止拆行。颜色、字号、行距、标注与原有纠错继续生效。

## 已执行的验证

最终构建为 `cache/preview-builds/2026-10-21T06-34-52.520Z/app`，检查报告和桌面报告在同级目录。113 项逻辑检查和 36 项实际 Electron 桌面回归通过，无跳过、失败或重试不稳定项。

同级 `verification.json` 独立核对了当前 63 个源文件、八个预览输出和原 `out` 五个文件的数量/摘要；另核对实际检查入口、冻结文稿/MP3/数据库、打包 ASAR、九份 ASR 资源以及交接 ZIP 的摘要。目录包仍未运行，0.8.4 的已完成长测证据保持原样。

- 三项新增逻辑检查覆盖 100,000 片段的末端分页、跨片段及空文字片段、NFKC/大小写/标点、重叠命中、Unicode 扩展汉字、非法查询与查询缓存切换。
- 四项新增桌面检查覆盖十万句/第 5,000 页/最后一句、跨阅读页命中、折叠展开、720×600 小窗口、暂停和播放中的媒体状态、纠错/导入/预览/切集后的快照失效，以及 worker 资源真实加载失败后的重试。
- 竞态检查在事件交付处暂缓真实 worker 已计算的结果，分别取消搜索或实际纠错，再交付旧结果；没有伪造结果数据，旧内容均未恢复到新界面。
- 最初两次定向检查的失败来自测试导航：预置进度没有选中目录，而“我的书架”名称还包含数量。修正导航后完整回归通过。十万句截图暴露的六位序号拆行已修复；失败与截图保留在早期 `test-results/transcript-search-dev5-*` 目录。

十万句测试采用可重复的合成文稿和 WAV，仅用于性能范围与交互，不代表真实音频时间精度。另用《呐喊》原始 43 分钟 MP3 对应的 1,006 段实际冻结 ASR，在复制的用户数据中执行同一 UI；最终记录为 `cache/asr-evaluation/transcript-search-runs/2026-10-21T06-43-14.966Z/report.json`。固定序号 15%、50%、85% 的查询分别定位到第 150、503、855 片段（从零计数）；“没有”共 42 个句范围，首页及末页逐条与独立字符归属扫描核对。四次查询和定位均保留 1.5 秒/暂停状态，文稿不变，原数据库摘要保持，原 MP3 与冻结 JSON 的摘要、大小/修改时间保持。没有重新运行识别模型。

该轮查询到结果观察约 13–59 ms，不包含索引首次准备，不作为所有设备的性能门槛。真实页面和小窗口截图已检查。此检查不证明 ASR 文字正确率、人工发音边界或安装版可运行。

## 复现

```powershell
npm run check
npm run build:preview -- --version 0.10.0-dev.5
$env:RALB_APP_ROOT = '<上一步 appRoot>'
npm run test:desktop
Remove-Item Env:RALB_APP_ROOT
npm run test:transcript:search -- --app-root '<appRoot>' --report '<已通过的真实 EPUB 检查 report.json>'
```
