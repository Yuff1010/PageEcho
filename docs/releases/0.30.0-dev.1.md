## 变化与入口

上一版光影太弱，本版将新拟态落实为近同色表面、左上高光／右下暗影、凸起控件和凹入选中。导航、搜索、导入及播放控件使用共享材质；密集工具按组塑形，封面动作采用短影。两类书架保持共同尺寸、内容与操作，阅读正文纸色独立。细节见 [风格说明](../NEUMORPHIC_STYLE.md) 和 [设计规范](../DESIGN_SYSTEM.md)。

左下角齿轮 → 外观设置 → **视觉风格**，选择“新拟态／极简留白”。未设置时默认新拟态；风格与界面主题分别保存，切换立即生效，重启后恢复。存储失败保持此前选择并直接提示，不覆盖明暗偏好或声音会话。
