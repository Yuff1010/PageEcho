## 交付内容

书架视觉预览采用“极简留白 + 轻新拟态”：暖灰／纸白和炭灰背景、低饱和绿、较少装饰边界；导入、选中分类、导航及主要播放控件使用统一的柔和光影。棕色与绿色封面稍加深，五种封面统一可读的浅纸色文字，播放器缩略图共用配色。

两类书架继续使用同一组组件和几何参数；没有增加 DOM、常驻文字或新的操作，也没有改变字体大小、头部高度、卡片尺寸、间距及播放细轨。共享配色随主题传到应用工具栏和面板，阅读纸色独立，保留现有主题偏好与保存行为。材质与封面颜色集中在 `appearance.css`；规则与范围见 [设计规范](../DESIGN_SYSTEM.md) 和 [视觉说明](../MINIMAL_STYLE.md)。
