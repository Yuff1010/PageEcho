# 0.39.0-dev.1 — 统一组件引导

交付日期：2026-11-02（America/New_York）。本版补齐离线组件入口及发现逻辑，复用原安装与启用事务；未发布在线组件源或模型资产。

## 变化

- “缓存与任务 → 存储与组件”接入同一 `ComponentSetup`／`ComponentInstallationPanel`，与首次生成、收听工具共用。删去独立旧配置入口，保留路径与模型诊断；三个标签仅挂载当前 panel，键盘切换继续有效。
- 组件／安装事件合并后刷新维护摘要和任务，存储读取串行合并，卸载后的晚结果不写回。安装目标、核对、取消、显式启用、历史恢复及活动任务保护仍由原 Main 执行，不因进入维护页自动执行。
- 附近发现兼容 `PageEcho-ASR-*` 和旧 `asr-component-*`，先筛出合法目录再限制读取数，避免无关发行文件挤占名额。没有递归全盘扫描或自动选择。
- 候选只表明路径可选，未检查时明确显示；选中后通过／失败另行区分。位置与可选解释放入 HelpTip，失败、真实进度和空间保持可见。
- Main 从未撤销 `KNOWN_BUNDLES` 生成离线包名／版本／设备／ZIP 字节数，UI 不复制版本表和不存在的下载地址。Windows x64 以外明确不支持；设备建议只用当前配置五分钟内的实际成功能力检查，不将 NVIDIA 名称当 CUDA 可用，不修改用户引擎、设备或书籍方案。
- 选包 → 核对 → 安装 → 启用显示为短步骤。重新打开已有安装活动时，锁定选择框显示 Main 的实际目标，避免显示空引擎或错误默认设备。

## 验证

- 类型、ESLint、649 项逻辑测试与格式通过。新增可信目录投影、不可变返回、已撤销包排除、不支持平台、未检查／过期／换配置建议失效及新旧目录有界发现回归。
- 最终 23 项相关桌面回归全部通过，无失败、跳过或重试：维护页 ZIP 取消不安装／不创建字幕、配置后自动刷新、明确检查失败、诊断保留；三标签仅一个 panel；CPU 检查不覆盖已选择的安装目标／书籍设置；包名及步骤来自真实 Main；帮助可通过聚焦打开；取消、晚选择、历史版本恢复、资源设置和阅读设置继续验收。
- 目视复核及计算样式断言确认每个折叠标题只有一套箭头和展开／收起文案，移除了旧组件专属伪元素，统一由共享 disclosure 控制。256 个源码、10 个输出、15 个 Python 运行文件与清单一致，根 `out/` 10 个文件保持原摘要。手工目录版 93 文件／94 ZIP 条目逐项校验，独立中文／空格路径、全新数据、仅系统 PATH 的真实声音／文字 worker 和重启位置恢复通过。
- 普通桌面能力检查使用受控 Python，安装核心使用受控合成小包，保持原实际 IPC／会话／队列；本版未重新跑大组件完整安装或模型质量。0.37 的真实 CPU／CUDA 和完整安装证据独立保留，不作为本版新结果。

初次 UI 回归中，旧断言仍要求已移入帮助的长段落；已改成聚焦说明图标并检查可见气泡。新增候选断言最初没有限定到目标行，发现多个真实附近组件后发生严格匹配错误；修为确切按钮所属行。目视检查发现共享标题缺父级 class，修正后又发现旧伪元素重复箭头／文案，已移除旧样式并补计算样式回归。维护测试的文本 `runtime.exe` 故意不是可执行组件，检查失败应显示明确 alert，不要求假运行库生成正常 probe 的结构化状态；缓存与组件错误同时存在时分别核对。相关失败保留，最终结果不与早期运行合并为一次。
