# 0.42.0-dev.1 — 大书架后台读取

交付日期：2026-11-03（America/New_York）。本版优化数据库批量和目标查询，保持旧完整 DTO、schema 18、用户数据和播放语义。不是摘要／详情分离的最终交付。

## 变化和测量

- 完整书架由 N+1 查询改为三次迭代数据读取及两次一致性快照控制，共固定 5 次；保持原书序、本地／在线同序号分支顺序和完整返回内容。
- 自动字幕、下一集、目录续载、离线计划、关联及移除改为定向读取。精确下一序号、任意后续章节、按数组位置的离线范围分别保持原义；启动关联恢复仍按原书架顺序保留 10,000 目标优先级。
- 复合数据在同一 WAL 视图读取，嵌套操作保留调用者事务。在线 pending 的空哈希、零位置／null 时长和注册音频优先级保留，人工文稿、映射、会话和模型不变。
- 相同合成数据三轮新进程：5000 本／百万集读取中位数 3674.90 → 2341.95 ms（减少 36.27%），一本十万集 416.48 → 253.76 ms（减少 39.07%）。完整 JSON 字节及 SHA 逐轮相同，两旧库摘要不变。测试没有测 IPC／首帧，系统磁盘缓存未清空。
- 百万集 read heap 中位数略增 5.3%，序列化未提速，约 290.62 MiB 的完整 JSON 仍存在；没有用 SQL 数减少宣称所有内存或界面体验已解决。数字、实际查询计划和边界见 [性能记录](../LIBRARY_PERFORMANCE.md)。

## 验证

- 类型、ESLint、725 项逻辑、格式通过；12 项 worker 协议和 172 项 Python 通过。
- 显式 `benchmark:library` 入口无参数不建库，九种非法／超限参数拒绝且不分配目录；2×3 集两轮小规模运行完整 DTO 摘要相同。历史百万行前后报告独立保留，新入口不执行旧源码或重写基线。
- 新增独立旧 SQL oracle 比较混合 DTO、排序及同序号、pending 已注册零值／null、实际查询计划、双连接 WAL 快照、调用者事务和失败回滚。后台准备回归另覆盖稀疏序号、目录加载时删书不复活、离线跨页选择及取消。
- 最终预览的 34 项相关桌面一次通过：无失败、跳过或重试，90.4 秒。覆盖播放器、电子书、首段 MP3、字幕准备／取消／部分结果、书架导航、来源续章、离线计划、文稿同步、原文导入及重启恢复。
- 最终 93 个发行文件／94 个 ZIP 条目逐项核验；独立中文／空格路径、全新数据、仅系统 PATH 下的实际 WAV、TXT worker、Windows 声音和退出重启位置恢复通过。该本机隔离运行不是干净 OS，也未重新运行真实识别模型或 NSIS；0.41 安装证据保留其原版本边界。
- 根 `out/` 的 10 个文件及用户／模型资料保持原样。本版 UI 几何与 shared contract 没有变化，不重写设计参数。
