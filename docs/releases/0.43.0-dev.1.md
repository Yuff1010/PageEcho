# 0.43.0-dev.1 — 书架摘要、目录分页与独立播放

交付日期：2026-11-03（America/New_York）。本版完成大书架摘要／详情分离，保留 schema 18、来源身份、人工文稿、阅读锚点及原用户资料。

## 变化

- 两种书架共用每页最多 100 张书卡；章节每次最多读取 100 集。切页、过滤或播放书不在当前页时，音频节点、URL 和会话继续使用，不把当前页冒充整本书。
- 新增轻摘要、完整单书、有界章节页、电子书摘要／单书和独立播放上下文接口。播放器依照真实排序的前后邻居连播，支持稀疏序号、同序号分支、100→101 跨页、在线续章和退出恢复；打开目录定位当前集所在页。
- 有声书库的导入、设置、字幕准备和缓存事件只返回目标变更／播放上下文，进度保存局部更新摘要。电子书导入仍返回明确的完整单书。旧页面、旧会话和旧保存回复不能覆盖新选择。完整 `getState()` 等接口仅保留诊断兼容，正常界面不调用。
- 工具按需取完整单书；等待期间保留单集操作并禁用整书纠错。离线计划跨分页保留选择，失败可重试，删除后不复活目标。
- 修复自动字幕过期回复将空上下文误判为删书、导致音频暂停的问题；失效回复不再终止当前收听。不可读单集仍保留下一集导航，已移除电子书显示明确提示。
- 修复电子书后台续页早于 DOM 提交发布窗口，导致快速翻页跳过一整块正文或恢复旧位置。导航只使用已提交窗口，后台排版恢复最新锚点；显式跳转仍保留固定目标。

一本十万集仍需在所选书范围排序，目录页／上下文中位数为 260.58／302.89 ms。以上是 Main Store／JSON 测量，系统磁盘缓存未清空，没有测 IPC 或 UI 首帧，也不是所有查询均瞬时完成的承诺。报告、失败记录和复跑边界见 [性能说明](../LIBRARY_PERFORMANCE.md)。
