# 0.35.0-dev.1 — 来源、续读、备份与存储

交付日期：2026-11-01。按此前列出的优先级完成七项优化，继续使用既有共享书架、阅读器和播放会话。

## 实际行为

1. 来源页面保留当前进程内的关键词、结果、详情、目录页及选章，切换分类或离开再返回可恢复。面板仍然互斥，离开取消请求，不将查询写入磁盘。
2. 音频／正文原封面保存到本地，书架、章节及播放器共用。重启或断网仍可读取，最多 512 个关联／64 MiB，缺失或回收后使用默认书封。已有旧书没有原封面信息时不会凭书名猜测。
3. 同源分章正文追加到同一本书，保留已有句子坐标、位置、书签、人工文稿及映射。目录可继续加载，阅读底栏可获取／取消下一章；追加后刷新旧末尾数据块，返回来源同步下载状态。
4. 音频／公共正文的“全部来源”最多三路并发，陆续展示首批结果，分源失败独立、可取消、最多 300 条；私人连接不自动广播查询。完整分页仍选择具体来源。
5. 插件检查结果、时间和版本保存在本机；可设置无参数 HTTPS ZIP 更新地址。检查只下载预览，同 ID 更高版本及权限变化经用户确认后才安装，保留回滚。
6. 应用设置新增“备份与存储”：导出书架、正文、位置、书签、文稿、映射、阅读偏好和已保存封面。选择备份先校验／预览，确认后重启恢复；保留旧目录和中断恢复能力。
7. 新构建和应用临时内容使用有回执的独立生成目录，默认关闭自动清理；提供配额、天数、每类至少两份、预览及单次 token。根 `out/`、模型、用户文件、未知旧目录和最终发行包不纳入此策略。

结构、操作与详细边界见 [设计规范](../DESIGN_SYSTEM.md)、[来源中心](../SOURCE_CENTER.md)、[插件 SDK](../SOURCE_PLUGINS.md)、[备份与存储](../BACKUP_STORAGE.md)。

## 限制

备份不是加密容器，排除原音频／原书文件、模型、缓存、凭据和插件执行包；跨电脑使用仍需提供音频并重新配置凭据／插件。展开内容上限 256 MiB。回滚数据保留在用户目录 `maintenance/rollback/`，不自动回收。

正文续读为按顺序追加；前置插入、旧章改序或实际收到不同旧文会拒绝更新，已保存内容不变。已下载章节不为探测改写而自动重下；目录检查最多 32 块，不能确认完整时提示核对，不宣称全书结束。原网站、私人服务和未来接口兼容性不由合成回归保证。

历史旧文件／测试源码批量删除被自动审批拒绝，仍未执行，实际释放 0 字节。本版没有换工具绕过拒绝，也没有将旧目录登记到新策略。NSIS、全新设备、模型识别质量和其他阅读器插件格式兼容不在本轮新增验收范围。
