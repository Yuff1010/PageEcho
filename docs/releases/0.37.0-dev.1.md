- 新增 `audit:python`、离线 `asr:patch`、固定 wheel 来源与每周 pip 更新。产品名、数据路径、数据库、插件协议和根 `out/` 保持原样。完整复现与边界见 [依赖安全](../DEPENDENCY_SECURITY.md)。
