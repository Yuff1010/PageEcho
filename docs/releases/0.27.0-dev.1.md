# 0.27.0-dev.1

完成日期：2026-10-27。Git 标签：`v0.27.0-dev.1`。

## 改动

- 修复“外观设置”和“应用信息”打开同一内容的问题：外观只管理应用主题，应用信息显示真实版本、运行环境及按需展开的数据／旧记录入口。
- 参考用户提供的网易云底栏布局，将播放器改为单排主控：左侧封面、章节标题和书名，中间居中播放操作，右侧图标工具。
- 删除左侧第三行字幕时长、领先量及小进度；字幕状态改为右侧图标，完整覆盖范围、真实分段与准备进度仍可打开。
- 播放进度使用横贯上缘的细轨，时间在悬浮或键盘聚焦时显示。保留原生滑杆、5 秒方向键、Home／End、毫秒位置和同一媒体会话。
- 保留等待字幕时立即播放、配置缺失、定时、错误与重试；这些条件消息位于右侧，不占用书名行。

共用尺寸、面板职责与维护边界见 [设计规范](../DESIGN_SYSTEM.md)。普通播放器高 84px；阅读模式保持已有单一底栏结构，进度轨位于来源／分页行与播放行之间。
