## 行为与使用

音频和正文来源的搜索结果、书籍详情共用原封面组件。适配器返回可选 `coverUrl`，主进程转换成本地不透明图片地址；图片缺失、超限、访问失败或不在允许域时回退既有默认书封。搜索仍保留书名、作者、简介与封面直接打开动作，不另加重复图标，不改变书架和阅读底栏的几何与音频会话。

主进程封面代理只接受登记候选，逐跳检查来源权限，不继承 Cookie／Authorization；限制为 PNG、JPEG、GIF、WebP，检查实际签名和尺寸，单图最多 2 MiB／1600 万像素／单边 8000，12 秒请求上限，最多 8 个并发、512 个候选，图片内存缓存最多 16 MiB／128 项。插件新增独立的 `coverOrigins`，未填时沿用 `allowedOrigins`，不沿用媒体权限。LibriVox 的 Archive 存储跳转限定同一作品／图片路径。Ting13 返回的部分 GIF MIME 实为 JPEG，安全输出类型按栅格签名决定，HTML／SVG 仍拒绝。

提供 bqg631 网站正文插件 `ralb.example-bqg631@1.0.0`。在来源中心的插头面板导入 `release/SourcePlugin-Bqg631-1.0.0.zip`，核对页面／正文 API／封面权限后安装，在电子书来源选择“笔趣阁 bqg631”搜索并选择章节导入。源码为 `examples/source-plugins/bqg631/`，制作步骤见 [教程](../MAKE_SOURCE_PLUGIN.md)，清单及返回值见 [SDK](../SOURCE_PLUGINS.md)。

该网站首页为 hash 单页应用，插件读取普通网页客户端的公开 API；正文采用网页公开请求编码，在原有受限引擎内使用随包锁定的 CryptoJS 4.2.0，不新增主程序依赖、账户或宿主加密权限。其 MIT 许可和上游完整性记录随示例保留；本次不保存网站正文或网页客户端脚本到仓库。

## 当前范围

原封面仅用于来源搜索和详情，尚不持久保存到书架。需账户认证的图片不借用个人书库密码；OPDS 目前仅加载同源封面。没有封面字段的来源仍显示默认书封。

bqg631 只验证一部作品的一章，不承诺全站／所有作品／未来接口均可用。来源链接暂指向首页，目录最多展示前 1000 项，每次明确选择 1–20 章；网站章节按一基序号标识，若网站重排目录，需重新核对身份。无登录、付费或验证码权限，无自动备用域轮换。插件兼容层、浏览器渲染、HLS、NSIS、干净设备验收及此前被拦截的存储清理不在本轮新增通过范围。
