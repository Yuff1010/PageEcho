# 0.35.0-dev.2 — 搜索原封面与显示尺寸

交付日期：2026-11-01。本版修复搜索原封面遗漏，并放大两类来源共用的封面。

## 原因与修改

听十三搜索页的 `.list-works-dl` 是文字信息块，图片位于同一 `li` 下的相邻 `.list-imgbox` 中。旧代码仅调用文字块内的 `querySelector('img')`，没有取得图片，因此搜索显示默认封面；详情页有独立的图片选择器，所以点入后可以显示原图。

提取器按同一张卡片中的书籍链接匹配图片，兼容内嵌图片和常见懒加载属性，继续通过既有来源域名限制与主进程图片代理展示。搜索不需要逐本打开详情补图。详情提取优先使用明确的书籍主图容器，再回退到通用缩略图，避免页面中更早出现的其他缩略图抢占。默认回退、凭据隔离及音频会话语义保持原样。

`source-book-result.css` 的共享参数将搜索封面由 78px 放大到 96px，详情由 58px 放大到 120px；≤800px 窗口分别使用 84px／96px。高度按同一 0.7 比例计算。两类来源共用尺寸，书架头部、书卡及播放器不受影响，参数所有权见 [设计规范](../DESIGN_SYSTEM.md)。
