# 0.41.0-dev.1 — 安装生命周期与关键桌面 CI

交付日期：2026-11-02（America/New_York）。本版是构建／验收维护版本，原目录程序继续为 0.39.0-dev.1，无需重新安装。云端临时生成的安装器用于验证，没有作为可下载发行资产发布。

## 变化

- 新增隔离 NSIS 构建入口。只接收成功冻结的预览，严格核对完整文件集与摘要、六字段应用元信息、v3 依赖锁、实际生产模块版本及复制字节。拒绝额外包配置、链接、路径越界、发行钩子和发布器；保持原 appId、当前用户安装、不提权、卸载保留资料及显式启动。
- `--plan-only` 在本机核对计划，实际 NSIS 仅在显式启用的 Windows Actions runner 运行。根 `out/`、冻结源码产物与 Python 资源前后核对；固定 `--publish never`，不修改系统安全策略。
- 增加真实安装生命周期：旧版本安装 → 默认 APPDATA 写入合成资料 → 新版升级 → 真实卸载并保留资料 → 重装恢复 → 再次真实卸载。核对真实程序版本、EXE／ASAR 摘要、当前用户注册项、书架／手工文稿／书签／音频位置与倍速音量／阅读锚点及偏好。初始有既有资料或安装即拒绝，不手工删残留来制造成功。
- 普通 CI 增加 worker／Python 逻辑，以及 21 项关键桌面流程；要求全部通过，禁止跳过、focused test 或重试。覆盖多容器解码、首段 MP3、哈希移交、退出恢复、字幕各阶段取消与部分文稿保留、分页及阅读位置恢复。
- Windows 临时路径规范化共用同一脚本。系统 Authenticode 元信息独立串行检查；普通单测检查空值／格式／信任状态，未签名不会被写成已签名。
