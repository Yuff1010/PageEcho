# 0.40.0-dev.1 — 质量回归维护版

交付日期：2026-11-02（America/New_York）。本版只更新评估工具和文档，程序继续使用 0.39.0-dev.1；不生成替代程序包，不要求重新安装。

## 变化和结果

- 新增 `quality:compare`。独立审计已交付的历史快照、参考清单、音频、报告及 checkpoint，再调用原评分入口重构本次文稿、重算 CER。连续语音只比较 `actual`；各配置原样本／参考字分母不可缩小，缺失和失败不折算成零错误。
- 每组分别报告增加、减少或相同。退出码 0 表示完整且没有逐组增加，1 表示完整但含增加，2 表示证据不完整或校验失败。未完成结果不给完整 CER，输出使用独占创建，不覆盖历史证据。
- 干声清单工具搬移仅接受与原 SHA 完全一致的显式路径；固定源包、参考文字、重采样及工具验证保留。影视评分严格区分只读诊断配置 v1／v2 的缓存位置；从 checkpoint 完整重构历史序号 ID 或当前稳定 ID 文稿，未知 ID、内容、时间或 warnings 不符仍拒绝。
- 顶层引擎／设备必须与 checkpoint 配置一致；验证子进程失败保存为不完整，而不会误用 CER 增加的退出码。
- 本轮通用组件 `0.8.0-sec.1` 执行两引擎 × CPU／CUDA × 三参考集，12 配置／244 样本结果全部完成，原始缓存首次运行、重放及 worker 重启复用通过。错误数与历史基线逐组相同。各集数字见 [质量回归](../QUALITY_REGRESSION.md)。CPU 是通用组件的 CPU 执行，不代表 CPU 专用发行包的本轮测量。

## 限制

结果只覆盖固定公开人工文字参考，不是总体准确率、默认引擎或真实小说验收。WhisperX 干声 CER 仍约 43%；真实小说固定 12 个切点人工听审仍 0/12，人工发音边界、角色／专名／广告和长单集质量待续。`qualityAcceptance` 明确保持 `not-determined`。本轮不调整识别算法、匹配阈值或基线，也不宣称剩余框架安全告警已修复。

程序／模型未发布 Release 资产；在线组件 feed、自动更新、NSIS／升级及干净 Windows 设备验收仍未完成。下一项按 [优先级记录](../OPTIMIZATION_NEXT.md) 推进安装升级和关键桌面 CI。
