## 修复

“正在后台检查字幕…”原先放在整个播放器右列的文字行中，起点靠近中间播放按钮；悬浮时又在该处显示同一说明。普通后台检查现在合入右侧现有字幕状态入口：同一个图标显示加载环，悬浮／聚焦提供短说明，原生详情入口仍保留已保存字幕的覆盖信息。检查完成后恢复原状态图标。

字幕等待的“立即播放”、组件配置、取消、加载及错误操作继续可见；其余文字提示靠右按内容收缩。检查与短集跳过提示共存时只在内联行显示跳过说明，可见文字和气泡内容一致。没有修改音频会话、后台任务调度、字幕数据或映射语义。

共用规则见 [设计规范](../DESIGN_SYSTEM.md)。本版不改变书架尺寸、风格选择、正文纸色或播放细轨位置。
