## 界面与使用

- 默认侧栏只保留当前文稿数量／版本、导入和校对／导出图标。短名称通过共用 Tooltip 在悬浮和键盘聚焦时显示，说明使用 HelpTip，实际失败直接显示。
- “字幕设置”是单个原生折叠。调整方案后直接显示生成方式、引擎、设备和下一集选项，不再套入另一层高级设置和整张引擎参考表；独立设置仍保留按需参考。
- 组件默认只显示真实状态。明确点击管理后才显示候选并加载安装与版本管理；长目录移到路径帮助。收起管理保留表单状态，维护页的完整流程保留。选择、检查、安装和启用仍为原有明确动作。
- 字幕工具、伴读与电子书阅读设置共用 340px 宽度、15px 标题、14px 内边距和 600px 最大高度参数。字幕工具只有正文区滚动，标题和关闭按钮固定；清除旧的双滚动规则及窄窗任务卡限高。再次打开工具从顶部显示。
- 使用同一个明确的应用面板底色计算和绘制透明面板，修复阅读纸色覆盖应用底色、重复透明混色造成的低对比度。导出菜单展开时关闭名称气泡，Escape 优先收起菜单并保留触发器焦点。
- 进度、取消、重试、部分稿、人工文稿与保存校验保持原链路；已完成任务不再重复占用工具面板。播放、正文锚点和设置草稿的保留行为由实际回归验证。
