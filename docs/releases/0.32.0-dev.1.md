# 0.32.0-dev.1

交付日期：2026-10-29（America/New_York）；本机报告使用 UTC。Git 标签：`v0.32.0-dev.1`。

## 改动

来源中心从固定音频网站拆为有声书、电子书、我的书库三个真正独立的面板，支持键盘选择。常驻动作使用图标与共享气泡，私人连接的管理动作收进更多菜单，720px 下保持紧凑。页面使用已有应用头部和尺寸，导入正文后进入原有电子书阅读器。

保留听十三，新增 LibriVox 官方音频 API。来源注册表、目录、数据库和媒体解析按来源身份路由；不同来源相同书目／分集编号不会串书。schema 16 保留原有 UUID、声音进度、人工文稿、原文及缓存哈希。LibriVox 允许 200 字查询，原听十三 20 字查询限制保留。

中文维基文库支持搜索、查看页面目录、明确选择 1–20 项并导入正文。个人书库支持 OPDS 1.x Atom 分类／搜索／分页，WebDAV 逐层目录，以及 Audiobookshelf 主电子书获取；TXT／EPUB 经现有原文 worker 解析后加入书架。重复导入相同来源端点、作品及范围会复用现有阅读位置，不按同名自动覆盖或关联。

连接凭据由 Windows `safeStorage` 加密保存，渲染进程与导出清单不含原凭据。连接清单先预览、后明确应用，要求相同清单 ID 的版本递增；不执行第三方脚本。请求支持取消、超时、大小限制及逐跳同源验证；WebDAV 每跳限制配置目录。部分 HTTP 响应、错误 MIME 和含 DTD 的 XML 不会成为已导入书籍。

结构、操作与参考项目见 [来源中心说明](../SOURCE_CENTER.md)，界面所有权见 [设计规范](../DESIGN_SYSTEM.md)。

## 当前范围

OPDS 仅支持 1.x Atom；WebDAV 只读逐层目录并在当前目录筛选；Audiobookshelf 本版导入主电子书，不接入其音频会话或远程进度同步。私人协议使用受控 HTTP fixtures 验证，未连接用户实际部署的服务器。维基目录仅表示当前页面链接，不承诺整书完整；连接清单需手动预览应用，没有远端订阅自动轮询，也不执行第三方 JS／JAR／DLL 插件。

现有听十三适配器与全部旧单元、桌面回归保留；本版没有重复运行其真实网络 ASR 长测。人工字幕质量、NSIS 安装与干净设备验收延续原有边界。本版没有执行此前被拦截的存储清理。
