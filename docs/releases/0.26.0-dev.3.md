本记录对应当前完整源码快照。此前远程仓库仅包含早期设计文档，因此本次提交同时纳入已完成的播放器、TXT／EPUB 阅读、字幕与原文匹配、书籍关联、组件与缓存管理、测试及构建脚本；不推断或重建未保存的旧版本源码。

## 本轮改动

- 侧栏、书架、播放器和阅读页的常驻动作使用准确图标，鼠标悬浮与键盘聚焦显示气泡，点击直接执行原操作。
- 共享导航改为紧凑图标栏；书卡移除重复装饰和关联文字，保留书名、格式／集数及实际位置。
- 字幕摘要保留真实时长、可听量或分段数，详细说明按需打开；取消、错误、重试与处理暂停继续可用。
- 保留两类书架的共同几何、同一套阅读设置、实测分页和单一听读底栏。
- 设计规则与版本提交流程写入 `AGENTS.md`，后续完成版本后自动提交、推送及打标签。

视觉问题及修改优先级见 [界面优化](../UI_REFINEMENT.md)，组件参数与维护边界见 [设计规范](../DESIGN_SYSTEM.md)。
