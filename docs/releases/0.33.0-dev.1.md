## 行为与使用

来源中心新增第四个独立的插件面板：从 ZIP 文件或直链导入，预览名称、版本、来源与网络权限后确认安装。一个包可注册多个音频／正文来源。安装后在对应来源列表选择它，再搜索、打开目录、缓存播放或选章导入。提供启停、更新、上一版回滚、卸载确认和逐源测试。

插件执行采用 QuickJS/WASM 与每次调用独立、可终止的 worker；网站访问由宿主代发，按批准的精确来源域逐跳检查，不继承 Node、Electron、文件系统、账户或应用 Cookie。提供 JSON、HTML／CSS 提取、URL 解析和有界 GET／POST。CPU、内存、响应、输出和请求次数均有限制，取消会中止网络与 worker。

音频和正文继续使用既有书架、缓存、阅读器和字幕链路。来源身份改为受约束的稳定插件命名空间，schema 17 原地保留旧 UUID、进度及资料。安装检查失败保持旧版；进行中的调用捕获原版本及权限，更新不切换当前调用。卸载后，已保存电子书、进度、人工字幕和音频缓存保留，已缓存音频仍可播放。

附中文维基文库真实来源示例，源码为 `examples/source-plugins/wikisource/`，生成包为 `release/SourcePlugin-Wikisource-1.0.0.zip`（1884 字节，SHA-256 `61ba9422f8413f2d8bcfaca66286146ff15ab364d2c9516275cff5eec89a8dd7`）。导入后在电子书来源选择“中文维基文库（插件）”，搜索“呐喊”并选择章节导入。

完整 SDK、包结构、打包命令及边界见 [插件说明](../SOURCE_PLUGINS.md)。这是本软件的 SDK v1，未实现其他阅读器的插件兼容层。

## 当前范围

插件方法同步返回 JSON，通过宿主等待网络；没有浏览器渲染、插件登录会话、持久 guest 配置／缓存、远端订阅轮询、DLL／JAR／随身听书兼容层。一次选择一个 ZIP，可用一个包注册最多 40 个来源。URL 包下载只允许同源重定向；音频仍采用完整 MP3，不将 HLS／其他未接入格式标为可用。正文每次选择 1–20 章，目录最多展示 10 页／1000 项；不是整书完整性保证。

版本 ZIP 存档在卸载后保留，当前没有自动清理旧包。新插件执行边界不等于任意第三方插件已通过审核。字幕人工质量、NSIS 与干净设备验收、此前被拦截的存储清理不在本轮新增通过范围。
