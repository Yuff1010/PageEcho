# M6 本地原文与音文匹配

初版日期：2026-10-20；更新：2026-10-25（America/New_York）。`0.10.0-dev.1` 独立预览已实现 TXT/EPUB 索引、按转写检索、空缺、人工校正与原文/转写切换。`0.10.0-dev.2` 已补整本原文搜索和 SRT/VTT 导出，见 [搜索与导出](READING_TOOLS.md)。用户指定《青山.txt》的实际导入和同作品首集流程通过。真实跨集/跨章的功能证据已补齐；删改判断、人工匹配和同步准确率仍待验收，不将映射数量当作正确率。

## 使用

`0.20.0-dev.8` 将原文阅读与管理操作分开：从底部播放器“听书字幕”进入，在顶部“转写字幕 / 小说原文”直接选择文字来源。选择按有声书保存，切集继续沿用；切回字幕再返回原文时，保留自由阅读位置与搜索草稿。

`0.21.0-dev.1` 增加电子书与有声书关联、基于有效映射的按位置双向切换，以及未匹配声音的转写字幕回退和校正筛选。已有电子书可直接作为伴读原文，无需再次选择同一原文文件。关联与切换步骤见[电子书与有声书关联](NORMAL_READING.md)。

早期 `0.10.0-dev.4` 采用匹配规则 4：检索兼容繁简体并保留原文显示/导出；整本原文的精确查找补足有界候选召回，重复精确位置保持待选，短句上下文须全局唯一。真实连续分集、旧/新 worker 对照及未听审摘录见 [真实跨集与歧义检查](ORIGINAL_SEQUENCE.md)；官方 EPUB2/EPUB3 与单个实际音频跨五章见 [真实 EPUB](ORIGINAL_EPUB.md)。以下历史记录保留原版本和验收范围，规则 5 的新增约束与复评另见[双侧锚点验证](ORIGINAL_ANCHORS.md)。

1. 打开一本有声书，从“听书字幕 → 小说原文”导入同作品的 TXT/EPUB，或通过“关联电子书”选用书架中的现有版本。原文绑定整本有声书，各集共用；独立电子书进度继续单独保存。“原文工具 → 原文来源”查看或更换绑定的原文，同名候选仍须确认后关联。
2. 尚无正式字幕时可按原文目录自由阅读；匹配按钮保持禁用，并提示先生成或导入本集字幕。正式字幕更新后会自动匹配绑定的原文；“原文工具 → 匹配与校正”可以手动重新匹配。生成稿预览不作为匹配依据。
3. 正文以段落排版，目录和搜索通过覆盖面板打开，不挤压阅读区。“回到播放位置”跟随已映射原文；正文滚动和翻页进入自由阅读，滚动工具面板不改变跟随状态。点击已映射文字或按 Enter/空格跳到对应声音，保留播放/暂停状态；拖选文字不会跳转。跟随状态下，当前声音没有原文映射但有对应转写时，显示标为“当前声音尚未匹配原文 · 转写字幕”的回退内容，可点“查看转写字幕”。回退不伪装成小说正文，也不高亮邻近原文代替空缺。
4. 在“原文工具 → 匹配与校正”展开“匹配与人工校正”，选择候选，或查找原文后填写起止句号与原始音频秒数。可用“显示片段”筛选“全部片段”“只看未匹配”或“只看已人工校正”，并可明确“保留空缺”。每页显示最多 20 个筛选后的转写片段，原文每次读取 60 句。原文字幕导出单独放在“字幕导出”分类。
5. 顶部“转写字幕”回到字幕阅读；其文稿工具只管理转写字幕的生成、导入、纠错和标注。原文校正独立保存，不改转写稿或音频；相同转写版本重新匹配仍保留人工选择、留空和时间修改。

相似度仅表示规范化文字接近程度；原文整句使用对应转写片段的时间，没有新增逐字声学对齐。不同原文内容或解析版本单独建档；再次选择旧版本可恢复其映射。转写稿或匹配规则变化后，旧自动同步暂不使用，提示重新匹配；规则升级保留同一转写快照的人工校正。

听书页可按当前有效同步点打开对应的独立电子书；阅读页“从此处听书”可查找包含当前正文位置的声音。多个有效位置由用户选择，没有有效位置则保留当前进度并提示准备字幕或匹配。自动双向定位只使用当前音频哈希、正式字幕与匹配规则版本有效，且识别来源仍为当前版本的映射。旧人工记录或来源变化后保留的校正可继续供核对，不作为自动跨模式跳转依据；不按章号、集号或百分比猜测位置。

## 导入、索引与保护

`0.20.0-dev.8` 界面验证：473 项逻辑检查与 21 项相关桌面回归通过，TypeScript、lint 和格式检查通过。真实 Electron 检查涵盖正文与覆盖面板、720×600 纸色/深色、来源和搜索草稿保持、拖选保护与键盘点句、无正式字幕时禁用匹配、末章精确定位、原文版本切换、人工校正及声学任务状态保护。证据位于 `cache/original-reader-controls-tests/` 和 `cache/original-reader-final-tests/`；独立预览为 `cache/preview-builds/2026-10-25T05-31-22.250Z/`，沿用现有预览数据，主 `out/` 保持不变。此轮未运行 opt-in 网站或真实模型脚本，不增加匹配质量结论。

- 文件只能来自原生选择器，renderer 不传路径。32 MiB 上限，读取前后复核大小/修改时间；取消、错误或处理超时保留原文与映射。
- TXT 先严格解码 UTF-8；带 BOM 的 UTF-16 单独处理，UTF-8 失败后尝试 GB18030。保留正文顺序与段落，识别“第 N 章”和数字标题；正文里的低编号附记保留为正文。无标点长段有界拆分，不丢弃文字。
- EPUB 按 container/OPF spine 的阅读顺序读取 XHTML 文字。不执行 HTML、脚本或外部请求，不将 ZIP 项解压到磁盘。校验路径、文件头、CRC、重复条目及解压上限；暂不支持加密、ZIP64、非 UTF-8 XML 等输入。实际桌面夹具覆盖存储/deflate、逆序清单、脚本排除及版本切回。
- TXT 解析版本 2、EPUB 解析版本 3 保存原文件 SHA-256、章节分区、段落与句子序号；EPUB 跳过没有文字的图片封面。最多 1,200 万字符、10,000 分区、250,000 句。分区包含前言、附记及文件本身的重复章号，数量不是出版章节总数。
- 读取、解析与匹配在有内存/60 秒期限的 Node worker 中运行；取消后回收 worker，可再次导入。退出禁止新处理并等待回收。SQLite schema v9 独立保存原文版本、单书绑定及音频哈希/转写快照对应的映射修订；旧书架、文稿、书签与进度保持。
- IPC 校验固定键、资产 UUID、哈希、修订、句号和时间范围；拒绝路径、额外字段、超长查询及越界/重叠同步点。异步结果提交前再次核对原文、转写和人工修订，防止旧任务覆盖新版本。

## 检索策略

匹配版本 4 仅在 main/worker 的检索规范化中用 OpenCC 将繁体折叠到简体；保存、显示及导出文字不改写。规范化文字的三元组索引及全局精确位置检索返回最多三个候选，支持跨最多四句/多个章节的窗口。长片段只有足够相似、无独立歧义且顺序一致时才自动映射。短片段可结合最多四段相邻转写：要求至少 18 个规范化字符、整本原文中唯一的精确上下文，再按各自字符范围还原原文句号。插话不能跨过，转换后重复或冲突保持空缺。每次最多 20,000 个转写片段；不保证所有措辞/删改都能自动匹配。

匹配版本 5 在上述规则后增加双侧已定位锚点的有界恢复，不降低全书自动采用阈值；人工留空、重复局部文本、声音间隔和区间边界继续限制采用。对冻结真实转写复评后，《青山》第 1–3 集仍为 53/137、62/164、35/153 段，《呐喊》同一音频的两种 EPUB 均仍为 276/1,006 段；新增、删除与改位置均为 0。此轮没有真实覆盖提升，人工匹配正确率及声音边界也尚未验收。字幕回退与筛选校正提高空缺内容的可读性和处理便利，不等同于已经完成自动匹配质量验收。完整规则、只读输入校验和拒配原因见[双侧锚点验证](ORIGINAL_ANCHORS.md)。
