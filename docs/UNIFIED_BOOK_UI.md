# 统一书架、阅读界面与设置页签

本轮以电子书阅读页为参照，统一有声书与电子书的视觉基础和常用操作位置，保留各自的阅读、声音与进度逻辑。它没有把录音字幕、小说原文和电子书朗读合并成同一种数据。

## 书架共用组件

`src/renderer/src/LibraryShelf.tsx` 中的 `ShelfBookCard` 同时用于有声书与电子书：共用封面、右下角主动作、标题与更多菜单、格式／集数、当前位置及封面上的跨模式图标。网格／列表布局使用同一组样式，电子书也使用书架的搜索、排序和最近阅读筛选。

主动作按内容变化：有声书继续播放／暂停，电子书开始／继续阅读；已关联电子书可通过耳机图标收听录音，有声书可通过书本图标阅读已关联电子书。没有关联录音的电子书可在更多菜单中使用系统声音朗读。移除记录与管理关联也位于更多菜单，解除关联在管理对话框内完成；这些操作继续执行各自原有的数据保护规则，视觉统一不改变记录的归属。

“有声书／电子书”切换是可刷新、可前进后退的书架路由导航，保留导航语义；它不是把同一页面的两段长内容滚动到可见位置。

## 阅读页共用视觉基础

两个阅读根节点都使用 `data-reader-design="book"`。`ReaderToolbar` 和 `ReaderFooter` 实际定义在 `src/renderer/src/ReaderToolbar.tsx`，共享样式位于 `reader-chrome.css`。工具栏采用相同的 60px 高度、38px 图标按钮、17px 图标及窄窗口间距。返回、书名、目录、搜索、设置、专注等操作使用相同的视觉层级，底部阅读状态与分页区域也共用界面配色和边框。

工具栏和底栏采用应用的浅色／深色界面主题；正文采用独立阅读配色。阅读面板的透明度和控件颜色继续由实际底色计算，不把应用深色主题强加到纸白正文。

正文排版统一使用 `useReaderPreferences`：默认宋体、20px 字号、1.8 倍行距、680px 最大正文宽度和米黄背景（`#F4EFDF`／`#39382F`），包括字重、字距、段间距与首行缩进。实际可用宽度仍受窗口限制。`reader-consistency.css` 将这些偏好应用到转写字幕和小说原文正文，覆盖早期伴读页独立的字号、字体与配色。

共享外观并不取消功能区别：

- 有声书阅读保留“转写字幕／小说原文”来源选择、跟随当前声音、自由阅读、原文匹配与校正，以及录音播放控制。未匹配声音仍保留空缺，并可显示明确标注的实际转写字幕。
- 电子书阅读保留章节与书签、独立阅读进度，以及 Windows 系统声音朗读。朗读与录音的播放控制继续互斥。
- 两类正文现在都使用 `ReaderPreferences` 的“排版／外观／翻页”。伴读的分页、连续滚动、单栏／双栏、分页动画、动画时长、平滑滚动和减少动态效果均接入实际正文行为。

### 共用分页基础与有界正文窗口

电子书使用 `useEbookDocument`，转写字幕和小说原文使用新的 `useCompanionPagination` 与 `CompanionReadingViewport`。两者共用 `reader-dom.ts` 的列宽／列间距测量、可见句子／字符锚点与恢复函数，以及 `motion.ts` 的翻页动画、仿真书页快照和系统减少动态效果判断。`companion-pagination.css` 的共享选择器覆盖电子书和伴读正文的列排版；电子书原有同值规则暂保留。

实际一页由可用视口高度、正文宽度、字号与行距等排版计算，不再把 60 句直接称为一页。伴读的 60 句仍是有界的数据／DOM 窗口，原文通过 `getOriginalPage` 按块读取；在同一个窗口内可能有多屏，跨过实测末屏才换相邻数据块。底部“当前内容 X / Y 屏”只表示当前加载内容的实测屏数，另显示按真实句子位置计算的全文百分比，不伪造未排版整本书的总页数。校对和人工编辑也保持局部窗口。

分页采用与电子书相同的横向列跨度和双栏间距。宽窗口的双栏每次翻动整组内容；窄窗口自动回到单栏。切换字号、布局、阅读方式或调整窗口尺寸时保留逻辑文字锚点：双栏页面即使从更早的句子开始，也不会把目标句改写成该双栏的第一句，导致下次缩窄丢失原位置。原文章标题兼容共用的章节锚点规则。

方向键、PageUp／PageDown、滚轮、下方按钮和横向手势都能翻页；连续滚动的按屏操作遵循平滑滚动及减少动态效果设置。跟随声音只定位已匹配的句子，不冒充手动翻页；用户翻页或滚动后进入自由阅读，可明确返回播放位置。搜索仍可跨数据块定位文字。没有匹配的原文不会跳向邻句。

伴读保留句子与声音的直接操作：点击已映射句子定位录音，拖选文字不改变声音。电子书使用左右半屏点击翻页；共享 `HelpTip` 按阅读来源分别说明，避免将电子书的点击规则错误套到伴读句子上。

### 唯一底部控制区

伴读通过 `ReaderDock.tsx` 的上下文与 `ReaderDockSlot`，把文字来源、字幕任务进度／取消、当前跟随状态、实测翻页和录音播放控制汇入同一个底部区域；不再为这些信息分别堆叠通栏。`PlayerBar` 的控制界面移入当前阅读页的挂载点，实际持久音频元素继续由 `player` 管理。非当前正文不占用导航插槽，来源切换不制造第二个播放器。

电子书的朗读、声音与速度选择和阅读导航也合入同一个 `ReaderFooter`，不再用另一块悬浮面板遮住正文。工具栏仍负责导航、搜索、设置等页面操作；正文使用扣除实际底栏后的空间进行排版。

### 偏好范围与旧设置兼容

全局阅读默认值由两种阅读页共用，并通过同一文档内的偏好变更事件及其他窗口的 `storage` 事件更新。电子书按正文 ID 保存专属覆盖，伴读按 `audio:<有声书 ID>` 保存，因此同一有声书切集继续沿用，而不会把录音的专属排版误写到独立电子书。

旧 `ralb:reader-preferences:v1` 仅在不存在新全局配置和当前有声书的新专属配置时，提供合法字号、行距和纸白／夜间主题的初始回退；已有新设置不会被旧值覆盖。修改后使用新的偏好格式。旧“折叠已标注片段”继续单独兼容。此处不升级数据库 schema，也不改变文字、声音或人工同步点。

## 设置导航是真正的页签

审计发现，“收听工具”原先把所有设置排在同一个长页面，三个入口只调用滚动定位；这是本轮发现的伪切换。它现改为三个互斥面板：“播放与定时”“字幕与缓存”“查看书签”。非当前面板隐藏，页签拥有选中状态和对应面板关系；切换时保留表单草稿、各面板滚动位置和独立消息，不重新提交设置或重启任务。

其他被审计入口原本已切换内容，不应描述为都存在相同滚动缺陷。本轮补齐或统一它们的 `tablist`／`tab`／`tabpanel`、`aria-selected`、`aria-controls`、面板标签与单个 Tab 停靠点，以及方向键、Home／End 操作：

| 页面       | 页签内容                         | 原有内容行为与本轮处理                                       |
| ---------- | -------------------------------- | ------------------------------------------------------------ |
| 收听工具   | 播放与定时、字幕与缓存、查看书签 | 从滚动定位改为真正的互斥面板，保留各页草稿与滚动位置         |
| 缓存与任务 | 存储与组件、转写任务、应用日志   | 原本已隐藏非当前内容，本轮补齐语义、键盘导航和响应式方向     |
| 离线准备   | 新建计划、已有计划               | 原本已切换内容，本轮补齐语义与键盘操作；切页不停止已创建任务 |
| 原文工具   | 原文来源、匹配与校正、字幕导出   | 原本已切换内容，本轮补齐面板关系与键盘操作，保留草稿         |
| 电子书导航 | 目录、书签                       | 原本已切换目录／书签内容，本轮使用完整页签与面板语义         |
| 阅读设置   | 排版、外观、翻页                 | 共用设置组件；两种阅读正文均实际执行翻页和动态效果设置       |

更换页签只改变当前展示内容，播放、字幕生成和离线任务继续按原状态运行。关闭面板或按 Escape 仍退出当前覆盖层；原生下拉列表打开时，Escape 优先处理下拉列表。

## 听读切换提示会消失

原先的“当前声音尚未匹配，已打开上次阅读位置。”长期停留，根因在 `BookConnections`：消息进入状态后没有计时清理，离开路由也不清理，`ReaderPage` 只要收到非空消息就持续显示。重新打开同一本书还能复现旧提示。

现在每条切换通知拥有独立序号：

- 显示约 4 秒后自动清除，旧通知的计时器不会关闭后来的同文案通知。
- “关闭阅读提示”可立即关闭。
- 离开目标电子书的阅读路由时清除，直接重开同一本书不会恢复旧提示。
- 自动消失或关闭仅处理通知，不修改阅读位置、录音时间、播放／暂停状态或同步映射。

提示内容仍区分真实结果：有效映射定位对应正文；没有有效映射时打开原有阅读位置，不用相邻句、章号或百分比猜测。
