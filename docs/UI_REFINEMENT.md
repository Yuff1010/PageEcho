# 图标操作与视觉层级优化

本文记录 `0.26.0-dev.3` 的诊断与取舍。`0.27.0-dev.1` 在此基础上将左侧字幕数值移至右侧图标详情，使用单排主控与上缘细进度轨；`0.28.0-dev.2` 进一步修复轨道与边界的双线。当前行为和参数以 [设计规范](DESIGN_SYSTEM.md) 与 [本版记录](releases/0.28.0-dev.2.md) 为准。

`0.29.0-dev.1` 开始极简留白与轻新拟态的书架视觉预览，只调整共享配色和材质，不改上述信息与操作规则。新的诊断、取舍和对比范围见 [视觉预览](MINIMAL_STYLE.md)。

本轮依据用户提供的书架截图检查文字密度、留白、字体层级、形状比例和一致性。附带的诊断文档作为检查维度参考；用户同时明确要求优化，因此分析后直接实施。改动沿用原有深绿／浅色主题与书架结构，不另建一套风格。

## 优先处理的三个问题

| 优先级 | 具体位置与问题                                                                                 | 影响                                                               | 本轮处理                                                                                                                               |
| ------ | ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| 1      | 底部播放器的“字幕与伴读”“听书字幕”文字操作，与长句字幕状态并排                                 | 持续占用横向空间，状态说明和主要播放动作争夺注意力；窄窗口更易拥挤 | 常用动作改纯图标；字幕摘要只显示状态图标、真实准备时长／可听时长或生成分段数与小进度；完整信息通过气泡及原详情查看，错误与重试直接可见 |
| 2      | 侧栏只有两项导航却占 192px；顶部搜索、导入、排序、布局分别使用不同边框与文字宽度               | 相同层级的操作形状和视觉重量不一致，标题与主要内容显得分散         | 侧栏统一为 80px 图标导航，窄窗口为 68px；两类书架仍共用头部，导入、分类、排序、布局改为统一尺寸的图标，当前选中项有颜色与形状反馈      |
| 3      | 书卡中封面英文／标语、资源类型、上次位置、关联状态以及跨模式操作重复出现；书名又被两个按钮挤压 | 小字多而层级弱，实际书名和阅读位置不突出                           | 去除重复装饰与关联文字行；保留书名、集数／格式和实际位置；来源用图标说明，跨模式入口放封面独立位置，标题行只保留书名与更多菜单         |

前两项主要属于一致性和操作密度问题，第三项属于信息层级与可读性问题。深绿配色、封面插画与圆角幅度属于风格选择，截图不能证明它们本身有缺陷，因此保留原主题。只有一本书时的空白来自实际内容量，不用放大书卡、重复内容或额外横幅填满页面。

## 图标与提示约定

- 常驻操作只显示图标，使用准确的 `aria-label`；书名、章节、真实进度、设置值和需要采取行动的错误继续使用文字。
- `Tooltip` 在鼠标悬浮后显示短说明，键盘聚焦时也可阅读；Escape 关闭提示并保留焦点。点击一次直接执行原操作，不要求先点击展开说明。
- 气泡使用顶层 popover、限制窗口边界，并观察触发器及气泡尺寸。展开菜单或原生下拉时不显示气泡，也不抢占它们的 Escape 键。
- `Tooltip` 不增加布局容器，保留原生按钮／选择框／summary、原 ref、ARIA 和事件处理。`HelpTip` 继续负责设置中的主动帮助按钮。
- 菜单、对话框和错误保留必要文字，避免把低频、歧义或破坏性操作变成需要猜测的无名图标。
- 翻页、朗读、转写／原文切换和返回阅读进度使用共用 `ReaderAction`；声音会话、映射、取消和分页逻辑不随表现改动。

## 验证

新增 `icon-controls.spec.ts` 在 1318px／720px 下验证常驻动作无可见文字但保留准确名称、悬浮与键盘气泡、边界、原生排序下拉、Escape、实际导入和布局切换；同一测试生成两种主题与两类书架的截图。

`player-chrome.spec.ts` 在 1180px／720px 下验证短字幕摘要的真实数值、完整详情、播放器控件边界、气泡与声音会话保持；`reader-consistency.spec.ts` 增加阅读图标、来源区分、焦点与原位置／声音保持验证。既有书架几何、分页、进度取消及设置回归继续执行。完整结果与目录包路径以 [交付说明](DELIVERY.md) 为准。
