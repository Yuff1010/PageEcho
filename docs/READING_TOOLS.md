## 使用

在“伴读阅读 → 小说原文”展开“搜索整本原文”，输入 2–100 字符。搜索兼容繁简体，忽略大小写、全半角、空白和标点；可跨同段相邻句，不跨自然段或章节。结果按原文顺序，每页 20 处，相同句范围合为一处。点结果收起搜索并定位原文，进入自由阅读，播放位置及暂停状态保留；重新展开可继续查看结果。

文稿阅读标题旁的“字幕导出”可选择 SRT 或 WebVTT。“小说原文”中展开“字幕导出”后使用“导出原文字幕”。选择保存位置后生成 UTF-8 文件；取消不会写入，已有目标文件在替换失败时保留。导出尚未采用的生成稿预览前，需要先明确采用。

导出使用当前保存的原媒体毫秒位置，不因倍速、片头跳过或广告折叠而改变。原文仅输出当前集已映射范围，人工同步点生效，未匹配段落留空。相邻转写片段若映射同一句原文，会分别输出整句及各自时间，不生成新的逐字声学时间；因此可能出现相邻重复原文句。文稿、原文及匹配修订在保存对话框前后均复核，旧请求不能导出已经失效的版本。

## 复现

```powershell
npm run check
npm run build:preview -- --version 0.10.0-dev.2
# 使用上一步返回的 appRoot，保留正在长测的 out/
$env:RALB_APP_ROOT = '<appRoot>'
npm run test:desktop
Remove-Item Env:RALB_APP_ROOT
npm run test:reading:tools -- --app-root '<appRoot>' --report '<已通过的 original-rematch report.json>' --text '<同版本 TXT 路径>'
```

此检查不替代 M3 人工听审、真实跨集/跨章匹配准确率、完整 M4B 长测，以及安装版/干净设备验收。TXT/EPUB 的搜索范围和格式限制沿用[原文说明](ORIGINAL_TEXT.md)，字幕单次最多 32 MiB。
