# 人工话轮端点审计

日期：2026-10-20（America/New_York）。对已经完成的四组连续 AISHELL-4 worker 输出补充时间诊断，产品仍为 0.8.4。本轮没有重新运行模型。结果只覆盖文字完整匹配的话轮，不能作为整段同步准确率、人工音素边界或有声书质量验收。

## 参考与规则

沿用 [连续参考](CONTINUOUS_REFERENCE.md)中固定的三段音频、25 个话轮及 1012 字，参考清单 SHA-256 为 `83e892faf6b4c426ad4ddde0211451bdf5eacbb1eb62c9b94468215f2be10896`。数据论文说明转录由人工标注、复查，并用 Praat 校准说话人分布和语音片段切分；TextGrid 提供各片段的起止时间和文字，见 [AISHELL-4 原论文](https://arxiv.org/pdf/2104.03603)。这些是话轮端点，话轮可能包含停顿，没有人工逐字或音素时间。

这是已知识别结果之后增加的审计，不是盲测。首次计算端点误差前，工具固定以下规则，不根据时间误差筛选或修改参考：

- 完整话轮至少有 12 个规范化字符；NFKC、大小写归一化后仅保留字母和数字，不转换数字读法或同音字。
- 话轮全文必须在整段人工参考和整段实际识别字符流中各出现一次。重复出现、文字不完全匹配、过短及失败话轮均保留原因和分母。
- 两侧必须恰好落在完整原生词/字单元的边界。若落在一个不可分单元内部，则排除，不均分时间。使用原生单元的时间，不用阅读句子合并后的时间包络。
- 正误差表示模型晚于人工端点。绝对误差报告中位数、最近秩 P95 和最大值；无匹配时为 `null`，不记为零。
- 单列每组的条件匹配集合，以及四组共同匹配的相同话轮集合。完整 1012 字的 CER 独立计算，不剔除识别错误来改善全队列成绩。

工具重新核验固定源标注、样本选择、媒体哈希、worker 缓存身份和所有窗口，使用当前完整重叠上下文重建原生单元，要求重建文稿和复核标记与实际保存结果相同。报告保存 worker 报告、文稿、checkpoint 和评分代码的 SHA-256；没有更改产品对齐规则或打包资源。

## 实际结果

原始审计为 `cache/asr-evaluation/utterance-timing/2026-10-20T23-58-22.151Z/report.json`。四组均完成 3/3 样本；每组保留全部 25 话轮。

| 引擎 / 设备       | 完整匹配 / 全部话轮 | 起点绝对误差：中位数 / P95 | 终点绝对误差：中位数 / P95 |
| ----------------- | ------------------- | -------------------------- | -------------------------- |
| Paraformer GPU    | 4/25（16%）         | 137.5 / 240.4 ms           | 368.1 / 752.7 ms           |
| Paraformer CPU    | 4/25（16%）         | 137.5 / 240.4 ms           | 368.1 / 752.7 ms           |
| WhisperX GPU      | 0/25                | 无匹配                     | 无匹配                     |
| WhisperX CPU int8 | 0/25                | 无匹配                     | 无匹配                     |

Paraformer 两组恰好匹配相同四个话轮，均来自对话段末话轮或另一单人段；其余 21 话轮全文存在识别差异。WhisperX 每组 25 话轮均有文字差异，因而没有符合此规则的端点测量，不能据此认定它的时间戳更好或更差。四组共同匹配集合为空，比较字段全部为 `null`；本次无法提供两引擎在相同话轮上的端点误差比较。

即使在这四个条件匹配话轮内，Paraformer 终点最大偏差仍为 752.7 ms。覆盖率只有 16%，且原生单元可能包含停顿/标点对齐时长，不能把该数值推广到所有句子或宣称整体同步通过。完整队列 CER 保持原值：Paraformer GPU/CPU 为 85/1012、84/1012，WhisperX GPU/CPU 为 191/1012、189/1012。
