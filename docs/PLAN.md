# 开发计划

更新日期：2026-10-21（America/New_York）

## 1. 目标与当前状态

做一款自己日常使用的 Windows 听书软件，以“保留现有演播音频，同时看到同步文字”为核心。

按新增需求，`0.11.0-dev.1` 增加独立“正常阅读”：无需音频的 TXT/EPUB 书架、章节目录、分页/方向键、全文检索、排版设置及持久阅读位置。schema v10 保留原音频/文稿/原文数据，118 项逻辑和 38 项桌面回归通过。独立预览启动和范围见 [正常阅读](NORMAL_READING.md)，原 `out/` 基线保留。

M0/M1 工程与本机源码验证、M2 人工时间戳伴读已完成。M3 已完成 Paraformer/WhisperX CPU/GPU 首轮评估，并在 0.4.0 接入 SQLite 任务队列、受限 IPC、逐块阅读、取消/重试、重启续接、生成稿预览和小范围纠错。用户指定歌曲的整首应用流程已通过；完整听书质量与默认引擎仍待验收。打包 EXE 受本机 Device Guard 限制，运行及干净设备验收保留。记录见 [M0](VALIDATION.md)、[M1](M1_VALIDATION.md)、[M2](M2_VALIDATION.md)、[M3 首轮评估](M3_EVALUATION.md) 和 [M3 应用验收](M3_APP_VALIDATION.md)。下列里程碑均按验收结果推进，不预先承诺未经估算的日历排期。

0.5.0 已实现 M4 的最近播放、带备注书签、分钟/本集结束定时和单书片头片尾设置，schema v5 保留旧数据，见 [M4 日常功能验收](M4_VALIDATION.md)。M3 质量与 M4 发布验收仍有待完成项目，不将整阶段标为完成。

## 2. 范围

### 第一个可日常使用的版本（M0–M4）

- 本地文件/文件夹导入、书架、章节目录及最近播放。
- 播放、暂停、倍速、快进快退、自动下一集、断点续播。
- 句级转写稿、高亮、自动滚动、点击跳转、手动浏览后返回当前句。
- 转写任务状态、取消、重试、已有片段复用和缓存管理。
- 基本文稿纠错、简单定时停止、书签、单书片头片尾设置。
- Windows x64 打包验证；其他架构按实际设备需求后续扩展。

### 本地版本稳定后（M5）

- 选定一个在线书源，接入搜索、详情、目录和音频地址解析。
- 登录会话、必要请求头、音频缓存、网络错误及地址过期恢复。
- 当前集优先和下一集转写预处理。

### 后续增强（M6）

- TXT/EPUB 原文导入、音文跨集跨章匹配、人工校正与原文/转写稿切换。
- 文稿搜索和字幕导出。
- 云同步、网盘、广播、移动端及公开插件市场不纳入当前交付范围。
