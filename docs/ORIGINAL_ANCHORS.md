# 双侧锚点原文匹配与冻结数据复评

日期：2026-10-25（America/New_York）。匹配规则由 4 升至 5，增加有界的双侧锚点恢复；没有降低全书自动匹配阈值，也没有改写原文、转写文字或媒体时间。

## 解决的漏配

旧规则要求短句的相邻组合在整本原文中精确唯一。若前后两段已经可靠定位，但其中有少量识别错字，组合精确查找会失败；夹在中间的短句即使在当前原文区间只有一处，也会因其他章节的重复内容继续留空。

规则 5 在旧规则完成后，只检查两个已有定位之间的完整未匹配区间。它不按集号推断章节，也不把新恢复出的句子连续当作下一轮锚点扩大搜索。

- 前后定位都必须在本次转写片段中存在，原文坐标须严格递增且不重叠。
- 中间最多 6 个未匹配片段、12 个原文句子；含两侧锚点的音频跨度最多 30 秒，相邻片段间隔为 0–1.5 秒，且处于同一已覆盖音频区间。
- 已人工保留空缺的片段会阻止整个区间恢复，不跨过广告、插话、未覆盖声音或用户决定。
- 首先要求中间所有转写文字拼接后，在该有界原文区间中精确且唯一地出现。仍有两个位置时继续留空。
- 近似恢复仅允许整个区间等长、至少 24 个规范化字符、首尾各 6 字一致、内部最多 2 字替换，且相似度至少 0.96；不尝试修补插入、漏字或边界移动。

新增候选使用 `basis: 'anchors'` 标识。它仍是自动文本匹配结果，不表示已经过人工确认，也不表示原文具有逐字声音时间。匹配版本升级沿用现有失效与重新计算机制，人工校正和留空继续由原存储逻辑保护。

## 为什么真实材料仍留空

对《青山》三集的 304 个未匹配片段继续只读诊断，共形成 50 个连续空缺块。下表按代码检查顺序记录每块的首个拒配条件，因此各项互斥；不是人工音频错误分类。

| 首个拒配条件                         | 连续空缺块数 |
| ------------------------------------ | -----------: |
| 没有双侧已定位锚点                   |            4 |
| 超过 6 个转写片段                    |           19 |
| 前后锚点映射在同一原文句或句范围重叠 |           13 |
| 声音片段间隔过大或重叠               |            5 |
| 含不足 3 字的片段                    |            3 |
| 整体文字不精确且长度变化             |            4 |
| 整体文字过短                         |            1 |
| 整体声音跨度超过 30 秒               |            1 |

所有空缺块都缺少“整块转写在两锚点严格内部区间唯一精确出现”的证据。常见情况是一个原文长句被识别成多个短段，邻锚点只读了长句的一部分，中间又有语气词、人物名识别差异或词序变化。因此直接放宽 6 段、30 秒等上限，不足以证明可以安全采用映射。未试听前，也不能将这些差异一概归为广告、演播删改或 ASR 错误。

已有三个适合从“未匹配”列表进行人工确认的精确候选：

| 音频片段                    | 识别文字摘录           | 原文坐标（从 0 开始） |
| --------------------------- | ---------------------- | --------------------: |
| 第 1 集，206.657–208.218 秒 | 我还没把手机给你呢     |                    43 |
| 第 2 集，320.413–322.014 秒 | 他已经半年没有说过话了 |                   134 |
| 第 3 集，366.985–368.966 秒 | 他看着陈硕手中的诊断书 |                   221 |

这三处在旧候选里已经有相似度 1 的结果，但短于独立自动采用所需的 12 字；周围未匹配文字又不足以满足整体恢复条件。它们是人工校正的有效入口，不是新发现的自动准确率证据。诊断完整区间、候选和拒配原因保存在同目录的 `qing-unmatched-diagnostics.json`，诊断脚本冻结为 `diagnostics-runner-started.ts`；再次核对只读源数据库前后 SHA-256 相同。

## 回归与复跑

`tests/unit/original-anchors.test.ts` 覆盖带少量邻锚点识别错误的重复短句恢复，并拒绝插话、本区间重复内容、长声音间隔和倒序锚点；既有原文与增量测试继续覆盖全书歧义、跨章、分集独立定位、人工空缺和旧修订保护。

```powershell
npm.cmd exec -- tsx --test tests/unit/original-anchors.test.ts tests/unit/original.test.ts tests/unit/original-incremental.test.ts
npm.cmd exec -- tsx scripts/evaluate-original-anchors.ts
```

复评脚本只使用本机已冻结文件。可通过 `--qing-report`、`--sequence-dir`、`--epub-report`、`--baseline-worker` 和 `--output` 指定其他已准备输入。缺少输入会在报告中记为 unavailable，不下载替代材料；覆盖率不作为正确率，新增或改位置的片段会单独列出并标记未人工审核。
