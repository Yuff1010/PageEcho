# 播放、字幕与电子书朗读

`0.23.0-dev.2` 保留 `0.22.0-dev.3` 的播放与朗读流程，并增加自动字幕的实时阶段、全阶段直接取消和更清楚的设置层级。普通操作只需决定读还是听。

## 已有录音

点击书架或播放器的播放按钮立即收听。已有正式字幕直接复用；未设置过字幕方案的书籍，在后台检查已配置的本地组件，按实际可用的设备与引擎建立“边播放边生成”方案，优先准备当前收听位置。声音不等待能力检查或模型加载。关联小说原文时，正式字幕落盘后继续自动匹配。

没有组件或当前不可用时保留普通播放，并提供配置入口；不自动下载模型。组件配置好后，当前播放或明确请求过的字幕准备会继续，不要求再次逐本选择引擎。已有人工稿和修订不会被播放动作替换。主动取消或失败的任务保持停止，明确点击“重新生成字幕”或任务“重试”后恢复。

高级字幕设置提供三个明确选项：

- 边播放边生成：默认方案，声音立即开始。
- 先准备字幕再播放：先等待当前位置的字幕，可随时选择立即播放。
- 仅手动生成：保留用户关闭自动字幕的选择；点击“生成本集字幕”仍可主动准备一次。

恢复应用的暂停音频、仅打开目录或字幕页不会启动新识别任务。切集会取消旧会话的组件检查；迟到结果不能修改旧书的设置或启动任务。旧版在线自动准备的引擎与设备经过可用性检查后继续沿用。

“生成本集字幕”会直接准备字幕；缺少组件或任务已经停止时才打开相应设置或重试入口。“字幕生成设置”只用于查看或调整高级操作，已有稿件重新生成仍先预览再采用。

字幕状态放在播放器内部；需要等待或配置时显示相应动作，常规进度仍通过字幕状态展示，不用浮条遮挡正文或搜索控件。关闭到托盘只取消尚未完成的能力检查，重新显示窗口后仍可准备字幕；恢复的排队任务失去组件时会明确提示配置。

自动准备开始后，阅读页直接显示阶段和进度卡，首段字幕出现后仍可查看紧凑状态。组件检查尚未创建任务时、排队、模型加载和部分生成后均提供“取消字幕生成”；停止确认期间显示“正在取消…”，完成后保留已有内容并明确显示已取消，普通声音继续。分段总数未知时使用不定进度，有总数后只按真实完成段数更新，不将动画或最远处理位置当作完成率。完整语义见 [字幕进度、取消与设置层级](SUBTITLE_PROGRESS.md)。

“收听工具 → 字幕与缓存”的高级设置默认收起。折叠组使用完整标题面板、左箭头、右侧“展开／收起”和展开内容缩进；选择框使用带右侧下拉箭头的独立方框，两者保留原生键盘语义。组件与缓存旁的状态说明和实时任务卡分别表示配置状态与正在进行的工作。

## 电子书与录音切换

书架显示可阅读／有声书关联状态，并提供直接阅读、收听及关联入口。正在播放的书卡显示暂停；暂停、继续不重新打开音频或重置进度。

“从此处听书”表示定位并开始播放。唯一有效同步点直接播放，多个位置先选择；没有同步点时提供“准备字幕并匹配”，一次操作启动工作，保留原收听位置，准备完成前不会按百分比猜测位置。

## 纯电子书朗读

没有录音的 TXT/EPUB 可点击书架“朗读电子书”，或在阅读页点击朗读按钮，从保存的阅读位置开始。使用 Windows 已安装的本地系统声音，正文直接作为朗读来源，无需转写字幕或 AI 模型组件。

提供暂停、继续、停止、语速和声音选择。按句准备音频并最多预取下一段，当前句高亮，跨页才翻到下一页；不一次加载整本书。手动翻页、目录或进度定位会暂停，继续时从新位置朗读。离开阅读页停止朗读；普通重新打开书籍保持安静。录音与电子书朗读互斥。

Windows 没有可用声音时显示明确状态，可在系统语音设置中安装声音；不会伪装成已播放。本机已验证中文 Huihui 与英文 Zira 声音。句内仅保存稳定字符锚点，不宣称词级声音边界。

## 验证范围

`playback-intent.spec.ts` 使用真实 Electron、音频、IPC、会话和队列，受控 Python 仅提供可延迟的能力检查及识别协议，验证自动准备不会阻塞声音；它不证明模型准确率。`ebook-speech.spec.ts` 使用实际 Windows 系统声音验证朗读、跟随、暂停、语速、手动定位及退出恢复。`handoff-smoke.ts` 在隔离开发环境变量的完整目录副本中验证原文 worker、真实系统语音 WAV 与媒体播放及重启进度。

冻结真实样本的原文匹配覆盖率、人工匹配质量及安装验收继续以各自的报告为准，本轮播放流程优化不增加准确率或干净设备的结论。

当前 `0.23.0-dev.2` 的 527 项逻辑检查及完整检查命令通过，77 项相关桌面回归全部通过，0 失败、0 跳过、0 不稳定重试，报告为 `cache/subtitle-progress-validation/desktop-results.json`。175 个源码文件与最终构建一致，主 `out/` 的 8 个文件未变，见同目录 `source-integrity.json`。实时进度、取消与设置回归入口见 [字幕进度说明](SUBTITLE_PROGRESS.md)；当前完整目录版已通过独立运行、真实 WAV、TXT worker、Windows 本地声音媒体播放及重启恢复验证，报告与 ZIP 校验见 [交付说明](DELIVERY.md)。
