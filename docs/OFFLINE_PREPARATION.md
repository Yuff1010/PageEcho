# 多集与整书离线准备

0.17 独立预览新增持久离线计划。书架每本书的“更多 → 离线准备”、章节目录的“离线准备”，以及“应用设置 → 离线准备计划”都可以进入；任务面板也有入口。

## 创建与查看

1. 选择书籍，再选整书、连续集范围或跨分页勾选分集。范围从第 1 集开始计数，每个计划最多 1,000 集，同时最多 5 个未结束计划。
2. 明确选择引擎、设备和在线音频预算。先预览，核对已有音频、未知大小、已有文稿和可用空间，再点“确认创建离线计划”。预览五分钟内有效；关闭或取消预览不会创建任务。
3. 在“已有计划”查看音频已备和整集字幕已备的集数，展开分集检查失败或需处理原因。离开面板后继续处理；退出应用后，下次启动恢复未完成计划，暂停和取消状态保持。

整书需要完整目录。在线书的目录可以先补全，再选范围；超过 1,000 集时会保留已补全的目录，提示分批选择，不把前 1,000 集称作整书。目录补全可取消，失败时不提交半份整书目录。

计划不会自动播放，也不会改写本书现有的手动／提前生成方案、引擎或设备。当前播放请求优先于计划下载，当前手动生成优先于后台计划，切集后持久计划仍可继续。后台最多一个计划音频准备过程和一个待运行的计划转写任务，完成后再补下一个，不一次创建数百个转写任务。

## 暂停、预算与重试

- **暂停计划**只暂停这一计划，等待其下载和独占模型工作收尾。多个计划共享的同一任务，或已被手动生成接管的任务，仍按其其他归属继续。
- **全局暂停处理**及**后台仅空闲满一分钟处理**同样约束计划；面板会显示对应条件。恢复全局处理不会恢复已单独暂停的计划。
- **调整预算**会终止使用旧预算的在途尝试，保留完整音频和已有字幕；已暂停或受阻的计划不会因此自动恢复。
- **重试失败项**明确重试失败或需处理分集。相同音频、引擎与设备可续接原失败任务及已校验分块；已取消的计划需要重新创建。已由用户取消的字幕任务须在任务页明确重试。
- **取消计划**保留已完成字幕、完整音频、书签和进度。源身份或音频版本变化不会悄悄改用新版本，需要重新核对。

预算只计算本计划保留的在线音频，包括原来已有的在线缓存；同一完整文件在计划内按身份去重。本地原音频不复制，不计入这一预算，所以纯本地计划可以填 0。模型和转写缓存另行占用空间。未知大小会明确显示，不能按 0 估算；下载中还会检查实际字节数与磁盘余量，单个在线文件上限仍为 256 MiB。预算不足、组件不可用或书源验证等问题会阻止继续批量处理，修复原因后明确恢复。

## 完成与资料保留

音频使用前校验完整 SHA-256，未完成计划重启后再次校验；计划还会独立读取实际媒体时长。正式字幕必须与该音频版本一致，覆盖从头到实际末尾，关联转写任务也已提交最终状态，才标记整集已备。跳转后的非连续片段、待采用的新稿和仅部分人工稿不冒充完成。部分人工稿、原文和已修订稿会保留，计划将提示先核对，不自动覆盖。

在线离线音频有单独的持久保留引用，独立于普通 **512 MiB 临时缓存**配额。“在线缓存”面板分开显示两种占用；普通 LRU 淘汰与清理预览均保留离线资料。文件被移动或改变会降为需处理，旧引用和文稿仍保留。

结束或取消计划后，可以二次确认“解除离线保留”。这只解除该计划的引用，使没有其他计划保留的在线音频以后可按临时缓存规则淘汰；不会立即删除文件，本地原文件也不删除。界面会区分上次处理状态与当前核对数量。历史已完成记录表示此前验证结果，不承诺持续扫描每个完整文件；再次实际播放在线缓存时仍校验完整内容。

存储、控制修订与共享任务归属详见 [离线存储](OFFLINE_STORAGE.md)。实际验收与已知边界记录在 [优化验证](OPTIMIZATION_VALIDATION.md)，小说人工准确率听审和后续编辑、导入、性能、安装升级与备份工作继续保留在 [优化台账](OPTIMIZATION_ROADMAP.md)。
