## 填写方法

先复制模板为新反馈文件，例如 `review-filled.json`，保留原模板。只修改每项的 `humanReview`；样本 ID、音频/原文/片段摘要、目标时间与 `sourceManifestHash` 均保持原样。顶层 `status` 不作为验收依据，工具从实际填写的字段计算状态。

| 字段                          | 填写规则                                                                                                                                                                               |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `listened`                    | 实际试听后设为 `true`。未试听保持 `false`，其余判断字段保持 `null`。                                                                                                                   |
| `spokenText`                  | 填目标范围实际听到的文字；前后上下文不算目标。无法确定填 `null`，不要把机器稿或出版原文直接当人工参考。明确没有语音时填空字符串 `""`，时间边界保持 `null`。                            |
| `mappingCorrect`              | 已选中原文时，判断该原文是否对应声音内容；没有映射时，判断保留空缺是否合理。明确正确填 `true`、明确错误填 `false`；无法核对原书或无法判断填 `null`。不要因时间接近而直接认定映射正确。 |
| `startErrorMs` / `endErrorMs` | 机器边界减人工听到的声音边界，单位为原媒体毫秒；正数表示机器偏晚，负数表示机器偏早。不能确定的边界单独保留 `null`，不能用 `0` 代替未知。                                               |
| `notes`                       | 可填写专名、删改、插话、听不清及需要更宽上下文等说明；没有备注可留 `null`。                                                                                                            |

时间计算示例仅用于说明符号，不来自这些录音：机器起点为 1,000 ms，人工声音起点为 900 ms，则 `startErrorMs` 为 `100`。若用试听片段内的位置测量，先加 `clipStartMs` 转为原媒体时间。推算的人工边界须在已提供的片段内；超出时保留未知并备注，重新准备更宽材料后再评估。

## 运行

开发环境需要 Python 3.12+；本工具只使用标准库和仓库中已有的评估函数，不加载模型、不运行打包 EXE。可直接调用：

```powershell
npm run asr:original:review:validate -- --manifest '<摘录包目录>/manifest.json' --review '<填写后的反馈.json>'
# 可选 --output '<新目录>'；已有输出一律拒绝覆盖。
```

默认在 `cache/asr-evaluation/original-review-results/` 原子创建独立目录，并发运行也不覆盖。输出包括 `report.json`、`summary.md`、输入原件和评估代码快照。校验只从包内 `clips/<id>.wav` 读取音频，不采用反馈中的新路径；片段摘要、单声道 PCM16/16 kHz、时长和数据完整性均复核。输入、原模板和音频不回写。

返回码 0 只表示文件关联和数据校验通过。缺样本、重复 ID、修改目标时间/摘要、多余字段、未试听却填写标签、非有限数、越界/倒序边界、被改动或截断的音频均拒绝；失败报告没有质量统计。默认目录使用原子临时目录创建，修复了早期两个并发运行同毫秒输出名称碰撞的问题；显式已有目录继续拒绝覆盖。

## 如何读报告

- `reviewStatus` 为 `unreviewed`、`partial-review` 或 `review-data-complete`；最后一项仅代表字段齐备。`acceptance` 始终为 `not-evaluated`，不自动批准质量或选择引擎。
- CER 复用 `asr_metrics.py`：NFKC、casefold、仅字母/数字，不转换繁简、同音字或数字读法。按已提供人工参考累计编辑距离/参考字数，不平均各段 CER。确认无语音的片段单独记录机器插入字数；总参考字数为零时 CER 为 `null`，有参考时 CER 可超过 100%。
- 自动映射、人工映射和保留空缺分别给出总数、已判断、正确、错误及未知数。比例只以该组已判断项为分母；没有判断时为 `null`。不把自动映射覆盖量称为准确率。
- 起点和终点各自保留已标注数量、平均有符号/绝对误差、绝对误差 p50/p95 和最大值，并列出完整起止边界数。不按 CER 或映射是否正确筛除大误差；未标注端点不补零。分位数采用排序后 `floor(n*p)`，封顶到最后一项。

统计只验证反馈与材料关联，不验证听审者身份，也不将固定摘录外推为整本书成绩。角色对话、广告、专名及实际发音边界的代表性质量验收仍按[开发计划](PLAN.md)保留。
