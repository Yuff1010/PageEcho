# 片段标注与折叠

0.8.0，2026-10-20（America/New_York）。已实现广告、片头和前情回顾的人工时间范围标注。JSON v1 文稿保持原格式；SQLite schema v6 在独立表保存标注。该功能不自动判断内容类别，也不自动跳过声音。

## 使用

1. 在伴读阅读中点击某句的“标注”，选择类型，并按原音频秒数调整起止范围。可以覆盖连续多句。
2. 勾选“折叠已标注片段”。完全落在同一标注范围内的句子会按本页合为折叠块；可展开文字、再次折叠或定位，播放/暂停状态保持。
3. 阅读状态栏的“片段标注”菜单列出全部范围，每页 20 处。没有识别文字的片头或静音范围也在这里保留；“按时间新增标注”可直接新增。
4. “修改标注”可缩小、扩大、移动或改变整个范围的类型。选择“正文”移除此标注。逐句标注时选择正文只清除所填范围，保留外侧的已有标注。

起止时间使用原音频的整数毫秒，界面输入秒、精确到 0.001 秒；已知时长时拒绝超出末尾。更新后的相邻同类型范围自动合并，每集最多 2,000 个。标注编辑使用模态窗口，范围列表按需展开，避免持续挤占小窗口阅读空间。

## 时间轴与数据规则

- 折叠只改变文字展示。音频不剪裁、不改写、不自动 seek；当前句和当前范围均使用真实媒体时钟及半开区间。
- 一句只与标注部分重叠，或跨越不同类型时，显示提示并保持展开。即使模型重新分句，也不会因为一小段广告重叠就把整句正文隐藏。
- 标注绑定 episodeId + audioHash + 原始范围，独立于文稿句子 ID、文字和修订。纠错、重新导入、生成预览采用和分块清理不会覆盖它；音频版本变化时不继承旧标注，删除书籍会级联移除。
- 标注有单独修订号。旧编辑拒绝覆盖新标注；更新范围、裁开重叠区间、保留外侧和合并同类型在一个事务内完成。管理菜单修改整处标注时，先核对原范围并在同一事务中替换，缩小或移动不会遗留旧范围。
- 失败保留原值。标注读取异常独立显示，已有文稿和普通播放仍可使用。当前不支持标注随 JSON 导入/导出。
- 阅读仍每页 60 个原句子。折叠块显示本页汇总；展开、翻页或回到当前位置均不一次渲染整本文稿。
