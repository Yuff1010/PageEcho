## 使用

1. 在书籍目录或播放器打开“收听工具 → 本书字幕准备”。本地音频和在线书籍都可设置。
2. 选择“提前分块生成，后台完成整集”，明确选择 WhisperX / Paraformer 与 CPU / NVIDIA GPU，保存。首次需在“伴读 → 生成转写稿”选择现有本地组件配置。
3. 打开一集后自动开始整集任务，沿用约 30 秒分块及重叠上下文。每块完成即保存、显示并可随播放高亮、滚动。
4. 自动播放及点击播放时，先检查播放位置起约 30 秒原始音频的处理覆盖；短集末段只等到本集结束。覆盖就绪后自动播放，任务继续处理整集。等待时可“立即播放”，或“取消等待”。处理耗时取决于设备和模型，30 秒是音频覆盖长度。
5. 可勾选“本集完成后准备下一集字幕”。当前集优先；下一集任务在后台排队。在线下一集会先缓存、测量时长，再转写；本地下一集直接处理。字幕完成后按音频哈希复用，不重复创建任务。

“手动生成”继续可用；“整集生成后播放”“播放时实时识别”保留为明确标注规划中的禁用选项。每本书的方案、引擎、设备、下一集选择独立保存并可在重启后恢复。

## 恢复与保护

- 播放恢复仍保持暂停，后台准备可以继续；用户点击播放后才检查缓冲并播放。
- 暂停、取消等待、跳转、切集、定时停止及音频错误会使旧等待失效，迟到的字幕结果不能恢复声音。
- 任务失败或组件缺失不会阻止普通播放；错误与重试入口沿用伴读和任务列表。
- 切集产生的取消可以恢复同一任务，复用有效分块；用户主动取消、失败任务需要明确重试，不在重新打开时反复启动。
- 保存过部分文字不等于整集完成。恢复原任务保留自动应用状态；手工导入、纠错和较新修订继续受已有保护，新稿需要预览并选择采用。
- 已有在线预处理设置在尚未保存新方案时保持原行为。显式保存新方案后，本集及下一集自动字幕由新方案控制；在线音频缓存选项独立生效。
- SQLite schema v11 增加按书关联的字幕设置表；迁移保留已有书架、进度、任务、文稿、原文及正常阅读。不要用只支持旧 schema 的程序打开升级后的用户目录。

## 范围

本次复用现有识别、时间戳和滚动阅读能力，不改变模型或声音识别质量。生成内容仍为“转写稿”；小说原文继续使用已导入 TXT/EPUB 的现有匹配及校正流程。

整集任务按原音频顺序处理。首次从较远的断点进入且没有该处字幕时，需要等待处理覆盖到当前位置，或选择立即播放；本次不增加跳转附近的独立推理任务。播放开始后不会因为字幕暂时落后而强制暂停。
