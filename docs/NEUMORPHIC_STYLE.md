# 新拟态风格与切换

用户反馈 `0.29.0-dev.1` 的效果太轻。该版主要是换色和短阴影，控件与底面仍明显分离，浮雕感不足。本次按用户的[参考图](https://picx.zhimg.com/v2-739be6c4b96526f703861e9c3017cd69_1440w.jpg)调整：已通过内置浏览器实际查看图片，提取近同色表面、成对的明暗影、凸起按钮和凹陷状态；保留现有桌面布局，不复制参考图的手机模块或低对比文字。

## 入口

主界面左下角齿轮 → 外观设置 → **视觉风格** → **新拟态**。这里也可切回“极简留白”；“界面主题”继续选择浅色、深色或跟随系统，正文纸色在阅读设置中单独选择。

未设置视觉风格时默认新拟态，明确选择后立即生效并独立保存，重新打开时恢复；切换风格不改变明暗偏好、书架、阅读位置或声音会话。保存失败直接提示并保留此前已保存的选择。

## 视觉规则

- 浅色主表面为 `#e6e8e5`，深色为 `#282e2a`。背景、侧栏和播放栏使用连续表面，凸面与底色接近。
- 主控使用 `±5px / 10px` 的左上亮影、右下暗影；选中／按下采用 `inset ±3px / 6px`。同一套材质变量控制两类书架。
- 密集分类／排序控件使用 `±2px / 4px` 的短阴影。导入分裂按钮作为一个整体塑形，播放器右侧工具使用一个凹槽，避免每个相邻图标叠影。
- 封面上的动作采用局部短影及内侧高光，保留书名可读性。选中同时保留强调色和填色；焦点、原生禁用状态、菜单语义与强制颜色轮廓继续有效。
- 所有颜色与光影来自 `appearance.css`。`--ui-compact-shadow`、`--ui-compact-pressed-shadow`、`--ui-on-cover-shadow` 补充主控与密集控件的材质尺度，组件只引用共同值。

范围为应用导航、两类书架、播放控件和外观面板；其他应用工具沿用共享配色。正文继续使用用户纸色。样式不改变书架尺寸、卡片顺序、头部、常驻信息、实际媒体进度或分页结构，也不增加新动画。

## 验证边界

前后比较使用同一批合成数据和相同的浅深主题、宽窄窗口；实际交互、风格持久化、保存失败及共享几何由桌面回归确认。最终证据、可运行目录与限制见 [版本记录](releases/0.30.0-dev.1.md)。
