## 示例内容

书名为“山间来信”“沿河漫步”“夜航手记”“四季慢行”“窗边的风”“远山有光”。正文是为本次展示编写的虚构短篇：林知回到山间小镇，收到一封旧信，循着手绘地图寻找河流转弯的地方。其他书籍也仅使用本次编写的短段落；未导入真实小说、第三方封面或用户书库。

封面由应用现有的默认书封组件绘制，书籍经真实 `ReadingStore` 与 TXT 解析器写入临时 SQLite 书库。阅读页使用产品已有的米黄配色、双页分页、20px 正文、1.9 倍行高和 900px 内容宽度。

## 隔离与核对

- 使用新建的临时用户数据目录，未读取日常书架、账号或阅读历史。
- 捕获期间禁用 HTTP(S) 请求，记录到的外部请求为 0。
- 未添加音频、未启动朗读或转写、未配置或下载模型。
- 两张图片均直接由 Playwright 的页面截图生成，无页面错误，已逐张检查显示效果。
- 原始捕获脚本和报告仅保留在本机忽略目录 `cache/readme-showcase/`。

图片只展示界面，不作为转写准确率、来源兼容性或全新设备验收的证明。
