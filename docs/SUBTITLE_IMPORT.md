# SRT / WebVTT 字幕导入

本功能进入 `0.19.0-dev.1` 独立预览。先退出旧预览，再双击 `cache/preview-builds/2026-10-24T04-12-59.108Z/start-preview.cmd`；它沿用 0.13 独立预览数据并升级至 schema 15，旧预览不能打开升级后的目录。它把外部字幕转换为伴读文稿，先预览，再明确绑定当前集。原有句级 JSON 导入入口保留。

## 使用方法

1. 打开一集音频，进入“伴读阅读”，点击“导入 SRT/WebVTT”。
2. 点击“选择字幕文件”，选择 `.srt`、`.vtt` 或 `.webvtt` 文件。此时只读取预览，不替换正式稿。
3. 核对目标集、编码、字幕文字和原音频时间。可显式填写固定时间偏移；修改编码或偏移后需点击“重新预览字幕”。
4. 核对转换提示，点击“绑定当前集并导入”，或“替换当前版本 N 并导入”。

SRT / WebVTT 没有本应用的音频 SHA-256，不能据文件名或字幕内容证明属于当前音频。界面展示所绑定的集数，使用者需核对文字和时间；文件摘要只是字幕来源标识，不是人工准确率认证。

预览每页最多 50 段，有效期五分钟。关闭面板、换集或播放会话变化会取消本次预览；字幕试听使用原有播放器，关闭时只停止所属试听。正式导入、纠错、撤销均继续使用原音频坐标，不随倍速改变。

## 支持格式与转换

| 内容           | 导入行为                                                                                              |
| -------------- | ----------------------------------------------------------------------------------------------------- |
| SRT            | 编号或缺编号的常见块、多行文字、CR/LF/CRLF、三位毫秒、大于两位的小时；点号毫秒作为兼容写法明确提示    |
| WebVTT         | UTF-8 的 `WEBVTT` 头、可选 cue ID、短／长时间写法、多行、NOTE、STYLE、REGION、常用 cue 设置和行内时间 |
| 已知字幕样式   | 转为安全纯文本，不执行 HTML、CSS 或外部资源；字体、颜色和视频字幕位置不保留到伴读排版                 |
| 实体与未知标记 | 命名／数字实体只解码一次；未知或不完整实体和不支持的标记保留字面并提示，避免吞掉正文                  |
| 注音与说话人   | 保留正文，注音展开为括号文字并提示；原来的标记和说话人信息仍在所保存的源文件字节中                    |
| 行内时间       | 核对其合法范围后移除，使用外层 cue 的时间，不据此生成声学逐字高亮                                     |
| 空字幕         | 计入来源统计并保留源文件，不伪造空白句或覆盖；全部为空的文件不能替换正式稿                            |
| 格式错误       | 时间损坏、逆序或超限等明确报错；不跳过坏尾块后声称整份文件成功                                        |

SRT 默认自动读取 UTF-8 或 UTF-16 BOM。没有 BOM 且无法按 UTF-8 解码时，可明确选择 GB18030、Big5、UTF-16 LE/BE；不静默猜中文编码。WebVTT 严格使用 UTF-8，其他编码需先转换文件。解码使用严格校验，失败时保留旧文稿。

格式处理依据 [W3C WebVTT](https://www.w3.org/TR/2026/CRD-webvtt1-20260520/)、[Library of Congress SRT 说明](https://www.loc.gov/preservation/digital/formats/fdd/fdd000569.shtml) 与 [WHATWG Encoding](https://encoding.spec.whatwg.org/)。这是伴读用途的格式接入，不宣称完整的视频字幕渲染合规性。

## 重叠、空档与时间偏移

同时出现的字幕按全部原始起止边界分段，并按来源顺序组合活动文字。例如 A 为 0–2 秒、B 为 1–3 秒，转换为：

| 原音频时间 | 伴读文字           |
| ---------- | ------------------ |
| 0–1 秒     | A                  |
| 1–2 秒     | A 与 B，各保留一行 |
| 2–3 秒     | B                  |

相同文字也不会因重复而自动删除。转换不挪动时间、不均分时间、不根据字数插值。预览显示源 cue 数、转换段数与重叠计数；正式阅读保留多行显示。

覆盖区间只取非空字幕的原时间并集。字幕之间的空档保留为未覆盖，不能据此认定是静音、已转写整集或已经完成离线准备。

固定偏移需要整数毫秒，默认 0。所有字幕整体提前或延后相同数值；出现负起点、时长越界或无效时间则整批拒绝，不裁剪到音频边界，不从字幕末尾反推音频时长。独立音频时长尚未知时会明确显示未知，之后采用仍会复核当时已知时长。

## 数据保护与来源

选择文件之前冻结当前音频版本和正式稿身份、修订及完整内容摘要。等待文件选择、读取或预览期间，正式稿发生任何变化，旧预览不能覆盖新修订，需重新选择。原有 JSON 导入也增加了相同保护。

明确采用前再次校验原音频完整 SHA-256、正式稿基线和当前时长；正式稿、来源原始字节／编码／摘要／转换统计、新导入修订、后台自动覆盖保护及命令去重在同一 SQLite 事务中保存。磁盘写满或中途错误会整体回滚。取消及退出会等待在途操作结束，迟到选择不能在数据库关闭后保存。

来源字节是选择时的完整快照，之后修改或删除外部字幕文件不改变预览内容。源 cue ID、原有设置、注释、样式和重叠结构可通过原始字节追溯；伴读文稿保存安全文字和原时间。来源存于本地数据库，不上传。

本次导入建立新的文稿基线，清除旧字幕编辑历史，并防止后台生成自动覆盖。此后小范围纠错、拆句和撤销保留来源的原导入修订，不把它冒称为当前修改后内容；再次 JSON／字幕导入或明确采用另一生成稿会建立新的来源基线。书签、片段标注、播放器设置与小说原文人工点分别保存，不随字幕导入回退。

## 大小限制

- 原文件不超过 16 MiB，转换后的整份标准 JSON 文稿也不超过 16 MiB。
- 来源 cue 与转换后的伴读段各最多 100,000 条；每段最多 10,000 个 UTF-16 单元。
- 最多同时保留两个预览；转换提示按类别聚合，最多 32 类。
- 超限整批拒绝，不只导入前半部分。复杂重叠可能使输出比原文件大，需要分集或整理字幕后重试。
