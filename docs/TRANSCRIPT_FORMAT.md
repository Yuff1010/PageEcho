# 句级时间戳文稿 v1

M2 使用人工标注的 JSON 文稿验证伴读。选择音频并开始加载后，进入“伴读阅读”，点击“导入 JSON 文稿”。文稿保存在应用数据库内，重启后可直接使用。

文件须为 UTF-8 JSON，不超过 16 MiB。可运行的中文语音示例是 `tests/fixtures/第32集-伴读样本.wav` 与 `tests/fixtures/reading-manual.json`：将这两个文件依次作为音频和文稿导入即可体验。样本的文字从“第十九章”开始，关联只依据音频内容版本和时间，不依赖文件名中的第 32 集。

```json
{
  "version": 1,
  "audioHash": "当前音频的64位SHA256值",
  "kind": "manual",
  "coverage": [{ "startMs": 0, "endMs": 10000 }],
  "segments": [
    { "id": "s1", "startMs": 1000, "endMs": 3000, "text": "对应这一段声音的文字。" },
    { "id": "s2", "startMs": 4000, "endMs": 7000, "text": "下一句对应的文字。" }
  ]
}
```

上方 audioHash 是说明文字，使用时需替换。未导入文稿时，阅读面板的“如何准备时间戳文稿”提供包含当前音频哈希的示例；也可用 PowerShell `Get-FileHash -Algorithm SHA256 -LiteralPath '音频路径'` 计算。导入接受大小写十六进制，内部统一为小写。

| 字段                | 约束                                                                                          |
| ------------------- | --------------------------------------------------------------------------------------------- |
| `version`           | 必须为整数 `1`                                                                                |
| `audioHash`         | 与当前音频内容一致的 SHA-256；不使用路径、书名、集号或修改时间代替                            |
| `kind`              | `manual` 人工标注文稿、`transcript` 转写稿、`original` 原文；只改变来源标识，不产生或推断对齐 |
| `coverage`          | 非空、有序且不重叠的已标注区间；最多 100,000 条                                               |
| `segments`          | 有序且不重叠的句子；最多 100,000 条，可为空                                                   |
| 句子 `id`           | 文稿内唯一、非空字符串，最多 128 字符                                                         |
| `startMs` / `endMs` | 原始音频的整数毫秒；`0 <= startMs < endMs`；句子须完整位于一个 coverage 区间内                |
| `text`              | 非空文字，单句最多 10,000 字符；按普通文本显示                                                |

仅接受示例中定义的字段。已知音频时长时会检查覆盖区间不超出末尾（允许整数毫秒舍入的 1 ms 误差）。所有时间使用原始媒体坐标；片头、广告或章节标题不改变坐标。

定位规则使用半开区间 `startMs <= positionMs < endMs`：

- 落在句子内：高亮该句。
- 位于 coverage 内，但不在任何句子内：显示“句间停顿”，取消句子高亮；这个状态只表示已标注区域暂无句子。
- 位于 coverage 外：显示“此处尚无文稿 · 未覆盖区间”，不将邻近句子强行延长。
- 到达音频末尾：显示“播放已结束”，取消高亮。

同一音频重新导入文稿会增加文稿修订号；格式错误或取消导入保留原文稿。音频内容变化后，旧文稿保留在旧内容版本下，界面提示重新导入，不显示旧文字。删除书籍会一并删除其文稿，不影响原始音频或 JSON 文件。

阅读面板每页显示 60 句。跟随播放时自动换页并定位当前句；滚轮、触摸、阅读区键盘滚动或手动翻页后进入自由阅读。“回到当前播放位置”恢复跟随。点击句子跳转到其起点，保持当前播放/暂停状态。

## M3 生成与纠错

应用内生成沿用 JSON v1，不新增隐含时间偏移。coverage 表示该区域已经处理，不表示文字正确或已经人工审核；模型没有识别出内容时，已处理区间也可能没有句子。

逐块生成只有在当前文稿修订未被用户替换时自动应用。已有文稿的新生成结果单独预览，明确采用时再次核对修订；人工导入或纠错阻止任务继续自动覆盖。小范围纠错保留句子 ID、startMs、endMs 和 coverage，仅更新文字与文稿修订；超出允许编辑范围或修订已变化时拒绝覆盖。句子拆分合并、大幅改写和重新对齐尚未实现。

## 人工片段标注

0.8.0 的广告、片头和前情回顾标注保存在 SQLite 的独立表，绑定音频版本和原媒体时间，不扩展 JSON v1 字段；重新导入或生成文稿不会覆盖标注。部分重叠句子不折叠，播放坐标不改变。当前 JSON 不携带标注导入/导出，说明见 [片段标注](TRANSCRIPT_REGIONS.md)。
