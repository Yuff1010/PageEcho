# 电子书阅读

“我的书架”统一管理有声书与电子书。顶部“有声书 / 电子书”在两种书架中都可见，可以随时双向切换；电子书不需要导入音频、时间戳文稿或配置转写组件。

`0.21.0-dev.1` 增加同作品关联和按位置双向切换：已有电子书可直接作为有声书伴读原文，当前位置存在有效映射时，可从声音打开对应正文，或从正文定位到相应音频片段。关联不依赖集数与章号相同，也不按阅读百分比换算播放秒数。

`0.22.0-dev.1` 增加 Windows 本地电子书朗读：普通打开只阅读，书架“朗读电子书”或阅读页朗读按钮才从当前位置开始出声。提供暂停／继续、声音和语速选择，逐句高亮并跨页跟随；手动翻阅暂停，退出停止，不需要录音或字幕模型。“从此处听书”现在定位并播放已有录音；无同步点可一键准备字幕并匹配。详见 [播放与朗读流程](PLAYBACK_FLOW.md)。

## 使用

在项目目录启动开发版（PowerShell 使用 `npm.cmd`，避免 `npm.ps1` 执行策略限制）：

```powershell
npm.cmd run dev
```

1. 点击“书架 → 电子书 → 导入电子书”，选择本地 TXT 或 EPUB。之后点击书架封面，进入独立阅读页 `#/read/<id>`，可直接刷新恢复。侧栏只保留“书架”和“书源”；“书架”回到最近查看的分类，底部播放器的“听书字幕”打开当前音频的伴读页。
2. 阅读页隐藏主导航和播放器，只保留正文、淡色书名及进度。鼠标移到顶部或底部显示工具栏，移入正文后自动收起。设置只在点击顶部设置图标后展开，再次点击、点击正文或按 Escape 关闭；鼠标悬停不会打开设置。
3. 默认“左右分页”，根据窗口、字号、行距和正文宽度实际排版。每章从新页顶部开始，不紧接上一章末段；双栏中每栏视为一页，下一章从下一栏顶部开始。正文分块开头不额外插入空白页，连续滚动仍按章节顺序自然衔接。点击阅读区域左半屏返回、右半屏继续（包括正文两侧留白）；拖选文字、已有选区、操作控件时不会误翻页。也可使用左右边缘按钮、底部上一页/下一页、鼠标滚轮、左右方向键、PageUp/PageDown 或空格（Shift+空格向前）翻页。触屏支持左右滑动。
4. 在“翻页”分类切换“纵向连续滚动”，可连续滚动整本书，临近边缘时加载前后正文。滚动条位于应用内容区最右侧，正文仍限制宽度并居中。底部按钮变为上一章/下一章，PageUp/PageDown 或空格继续按屏移动。平滑滚动可开关，连续按键累计目标位置；不再把固定 60 句当成一页。
5. 顶部目录支持筛选章节；全文搜索兼容繁简体，忽略大小写、空白和标点。Ctrl+F 打开搜索，点击结果定位并高亮。底部进度条可跳转，Ctrl+Home/End 跳至开头/结尾，F11 切换全屏。隐藏工具栏时按 Tab 可以用键盘访问操作。
6. 设置栏约 290px，分为排版、外观和翻页。在所有窗口尺寸下均浮在正文上方，展开时不改变正文宽度、位置或分页。关闭设置或切换分类不影响已生效的设置。下拉菜单沿用应用的浅色/深色配色、圆角、选中标记和键盘操作；打开下拉选项时 Escape 先关闭选项列表。
7. 翻页、滚动和定位自动保存进度，长句额外记住字符位置。返回书架、刷新或退出重开后，点击封面继续阅读；设置也会保留。重复导入相同内容保留进度；同名文件的正文改变后作为另一版本入库。

阅读页使用整个应用内容区，顶部“电子书书架”保存位置并返回电子书列表。未关联有声书时，原有“返回听书”或“有声书书架”仍可作为导航出口；关联后显示“从此处听书”，按当前正文位置查找相应声音。普通书架与阅读来源切换不改变录音播放状态；“从此处听书”是明确的播放操作，会定位当前音频或打开对应的一集并开始播放。目录、翻页和全文搜索本身不会跳转录音；电子书朗读进行中则先暂停，以便从新阅读位置继续。

书架、目录、阅读、伴读和书源使用同一套路由，支持刷新与前进后退：有声书 `#/library/audiobooks`、电子书 `#/library/ebooks`、音频目录 `#/audiobooks/<id>`、阅读 `#/read/<id>`、伴读 `#/listening`、书源 `#/sources`。两种模式继续分别保存进度，只有用户明确执行按位置切换且存在有效映射时，才更新目标位置。

## 关联同一本书

1. 在有声书的书籍菜单或目录页点“关联电子书”，也可在电子书阅读页点“关联有声书”。从现有书架选择对应作品；尚无电子书时可在关联窗口导入 TXT/EPUB。
2. 同名作品只作为候选推荐，确认版本后点“关联并用于伴读”。关联会把这本电子书作为有声书的原文，替换当前原文绑定；旧正文和人工匹配修订仍保留，可在之后重新关联时使用。内容哈希与解析版本相同、实际共用同一份原文的书籍，可以识别已有关系，不凭相同书名自动绑定。
3. 听书时从伴读页打开对应电子书：有当前有效映射则定位到声音对应的句子；已有原文但尚未加入电子书书架时，此明确打开操作会将其加入书架。当前位置未匹配时打开上次阅读位置，并显示未匹配提示，不把邻句作为当前位置。
4. 阅读时点“从此处听书”：只有一个有效声音位置时直接定位；同一文字对应多个演播版本或片段时，由用户选择。没有有效同步点时提供继续阅读或打开关联有声书准备字幕与匹配的入口，不任意选择一个声音位置。
5. “管理有声书关联”或“管理电子书关联”可调整关系；“解除原文关联”只解除该有声书的原文绑定，不删除音频、电子书正文、独立阅读进度或已保存的人工匹配修订。移除电子书书架记录也不会移除有声书所使用的原文。

按位置切换只采用当前音频内容哈希、当前正式字幕及当前匹配版本均有效的映射。缺少识别来源的旧人工记录、来源已变化后保留的人工记录，以及过期音频／字幕对应的映射不用于自动跳转；可保留供人工核对。多句共用一个片段时间时定位到对应片段起点；已采用逐句声音同步点时使用相应句子的时间，不宣称逐字定位。

小说原文尚未匹配的声音仍可阅读：在跟随状态下，有对应的真实转写字幕时，原文页会显示明确标注的字幕回退；“原文工具 → 匹配与校正”可筛选“只看未匹配”或“只看已人工校正”。这与独立电子书正文区分显示，详见[原文阅读与匹配](ORIGINAL_TEXT.md)。

匹配规则 5 的双侧锚点改进与冻结复评见[双侧锚点验证](ORIGINAL_ANCHORS.md)。本批真实《青山》和《呐喊》的覆盖数量没有提高，人工准确率和声音边界仍待验收；双向切换及字幕回退不改变这一质量结论。

## 阅读设置

- 排版：宋体、黑体、楷体和应用界面字体；14–36px 字号；常规/加粗字重，黑体和界面字体还提供中等字重。字体缺失时沿回退链使用本机字体。行距 1.3–2.4 倍、字距 0–3px、段间距 0–1.8 倍字号、正文最大宽度 360–900px，以及两个汉字的首行缩进开关。滑块显示名称、数值和单位，修改后即时重排。
- 紧凑程度：紧凑（1.5 / 0 / 0.3）、标准（1.8 / 0 / 0.7）、舒展（2.0 / 0.6 / 1.1），依次为行距、字距和段间距。细调这些数值后自动显示“自定义”。初始值为 20px、1.8 倍行距、0 字距、0.7 倍段间距、最大宽度 680px。
- 外观：纸白、米黄、浅绿和夜间四组背景/文字配色。初始米黄为 `#F4EFDF` / `#39382F`。可以分别选择背景和文字颜色，保存最多 8 组个人配色；对比度低于 4.5:1 时显示轻量提示。应用界面独立提供浅色、深色和跟随系统，可在阅读设置或“应用信息”中调整，不改变阅读背景。面板透明度支持 0–100%，默认为 0%（不透明），按当前设置范围保存。面板文字、提示、选中状态和控件根据阅读底色、应用主题与透明度叠加后的颜色自动调整，保证至少 4.5:1 的静态文字对比度；即使应用为深色、阅读背景为纸白、面板为 100% 透明也能看清。下拉选项使用同色实底，避免重复叠加透明度后难以辨认。展开面板调整配色时即时更新，避免颜色过渡途中产生低对比度。
- 翻页：页面布局可选择“单栏阅读”或“双栏阅读”。两栏共用整页阅读背景，以留白分隔，去除书本外框、额外底色、页边与书脊阴影，每次翻动整组左右内容；不足 900px 的窗口自动显示单栏，保留布局设置和文字锚点。正文宽度控制单栏的最大宽度。页面布局与动画分别管理，切换单双栏不改动画和时长，兼容此前保存的双页书本设置。
- 动画：横向分页支持无动画、平移、淡入、纵向推进、轻缩放、纸页翻转、擦除和仿真翻书，时长 100–400ms，初始默认淡入 180ms。仿真翻书保留翻页前的画面，让书页在书脊处转出和展开；快照不参与正文搜索、位置测量或交互，连续操作会清理上一张动画层。后台正文分块加载不会提前中断翻页动效，跨已加载正文边界时在定位完成后播放。连续滚动禁用页面布局和分页动画控件并保留其值；平滑滚动控制按屏移动，鼠标滚轮保留系统滚动手感。“减少动态效果”与系统偏好任一开启时，关闭阅读动画和平滑移动；系统已开启时在设置中说明原因。
- 范围：“所有书籍的默认值”调整全局默认，“仅此书籍”只保存修改过的字段，其余继承全局。单本覆盖 > 全局默认 > 初始值。切回全局时暂不应用本书覆盖，但会保留配置，重新切回即可恢复。“恢复全局默认”清空本书覆盖；全局范围的“恢复初始默认”恢复初始阅读设置。应用界面主题和个人配色始终独立于书籍范围。
- 专注阅读隐藏工具栏和辅助面板，保留右上角“退出专注”按钮，也可按 Escape 退出。Ctrl+鼠标滚轮仅改变正文字号，不改变应用界面缩放。下拉框、滑块、输入框等控件获得焦点时，阅读翻页快捷键不会抢占其操作。
- 书签：顶部“阅读书签”或目录旁的“书签”页签可查看、添加、跳转和删除。Ctrl+D 添加当前位置，最多每书 500 个；书签保存真实章节、正文摘要和稳定的句子/字符锚点。

## 存储与限制

schema v10 在 v9 上增加 `reading_books`，独立保存原文身份、当前句序号和最近阅读时间。TXT/EPUB 解析结果仍由 `original_documents` 按内容哈希和解析版本去重，与伴读共用不可变正文；两种阅读模式的访问检查和位置分开。移除电子书不会移除音频书或其伴读原文。

导入路径只来自主进程原生文件选择器。沿用现有 worker 的 32 MiB 文件上限、250,000 句和 10,000 章节限制，以及 TXT 编码检查、EPUB 安全解析。正文每次请求最多 60 句，搜索每页 20 处；renderer 仅保留当前附近的正文分块和有限请求缓存，随着阅读移除远端正文，过短的文本会加载到足以填满视口。分块是数据传输单位，与可见分页无关。EPUB 按阅读顺序提取文字，不渲染原书排版、图片、脚本或外链，不支持加密 EPUB。

句序号继续存于原有数据库；字符偏移、书签和偏好存于现有 localStorage，无需数据库升级。`reader-settings.ts` 负责 v3 全局默认及按不可变书籍 ID 保存的覆盖值，兼容 v1/v2 字段和缺失字段。阅读位置仍由 `useEbookDocument` 和 `reader-dom.ts` 以句子序号＋文本偏移恢复，不以页码或百分比反推位置。导入同一不可变书籍身份后可恢复位置。

当前项目没有 PDF 阅读器；本次设置仅用于 TXT/EPUB 的文字重排。未引入 PDF 排版控件。个人配色、书签和偏好保存在当前电脑的应用数据中，不提供跨设备同步；平滑滚动使用 Chromium 原生缓动，其时间不由分页动画时长控制。
