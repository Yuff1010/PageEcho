## 自动验证入口

`npm run verify` 串行执行 `check`、`test:dev`、`build`、源码生产桌面测试；`npm run verify -- --packaged` 再生成 NSIS 安装包并验证打包程序。任一步失败即停止依赖步骤，并以非零退出码结束；Device Guard 的明确拦截信息记为 blocked，不计为通过。

日志与 JSON 报告保存在 `cache/verification/<UTC时间>/`；`cache/verification/latest.json` 指向最新结果。报告保存计划中仍未勾选的任务及下一步文本，不自动勾选人工验收。桌面轨迹分别在 `test-results/verify-source/` 和 `test-results/verify-packaged/`。

本次最终报告为 `cache/verification/2026-10-20T02-59-46-039Z/report.json`（UTC 目录名，对应本地 10 月 19 日）。前一次运行的本地化 Device Guard 文案未被分类器识别，已经修复并加入中英文/乱码消息回归；最终结果正确记为 blocked，未更改系统策略。安装包为 `release/ReadAndListenBook-0.3.0-win-x64-setup.exe`，本轮未执行安装/卸载。
